accelon26 是 Accelon3 的跨平台平替：直接讀 .adb，不必轉檔、不必匯入。 全文檢索、詞典查詢、目錄樹、原書分頁與繁簡通檢，都在同一個視窗裡完成。

↓ 下載 Windows 版

Windows 10／11 · 64 位元 · 單一執行檔、免安裝 · 7-Zip 壓縮檔，約 7 MB

主要特色

快速搜尋

索引直接建在壓縮的資料庫上，邊打邊查。命中在本文裡直接塗紅， 多詞組（+ - * .）與 繁簡通檢一次搜完。

兼容 Accelon3 資料庫

直接開 .adb，資料格式完全不動。目錄、名詞、頻次、原書分頁都照資料庫自己的 <樹> 宣告長出來，沒有寫死的欄位。

小體積、無第三方依賴

單一 17 MB 執行檔，沒有安裝程式、沒有 Electron、沒有要另外裝的執行環境。 平常不連網，只有你按「檢查更新」時才出去。

軟件畫面

下載與安裝

  1. 下載並解壓縮

    下載 accelon26.7z，用 7-Zip 解開，裡面就只有一個 accelon26.exe。

  2. 放到 accelon3.exe 旁邊

    把 accelon26.exe 放進 accelon3.exe 同一個資料夾（也就是 .adb 檔所在的地方）。不需要安裝，也不需要管理員權限。

  3. 雙擊執行

    開啟後會自動列出同一個資料夾裡的資料庫。也可以用 📁 或直接把 .adb 拖進視窗。

打不開 7z 檔？ 7-Zip 是免費的解壓縮工具，到 https://sparanoid.com/lab/7z/ 下載 Windows x64 版即可（免安裝版解開就能用）。
