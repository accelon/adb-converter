dfb.adb 製作說明（丁福保《佛學大辭典》）

丁福保編《佛學大辭典》（1922 年初版）的 adb 版，31,585 條。詞頭按「詞條查詢」直接跳， 詞頭前有彩色小色塊標示該條的體類（術語、名數、雜語、經名、人名、書名…共 87 類）； 引文帶字元級的大正藏連結，點一個字就能落到《大正藏》那一頁那一句。

一、體例怎麼進 adb

BAUS 的原文把體例寫在釋文開頭，例如「　（雜語）猶言逐一也。…」。這些標記不是內文， 所以一律改成結構，不在詞條裡顯示成方括號：

  • 87 種體類「（術語）（名數）…」→ 詞頭屬性 <詞 t="術語">，閱讀端在詞頭前長出一個小色塊， 色相依 <集 scheme> 的順序表分配（表内容由頻次排，同一類別全庫同色）。
  • 同形詞頭 592 種（如兩個「阿彌陀經」）以 a="2" 序號區分，序號照 entryid 先後編，連續無跳。
  • 交叉引用 (參見：X) → <聯 n="X">：只有 X 確實在詞頭表裡才成鏈， 成鏈 5,891 條；查無此條的 400 條保留原文，不造點了會落空的死鏈。
  • 義項分段「（一）…（二）…」前插 <段/>，共 137 處／66 行。 帶段號的 <段 n=…> 是巴利藏幾庫的跨庫對齊鍵（會長出一顆 ¶N 的對讀晶片）， 本庫沒有對讀對象，所以只發不帶 n 的形式——它是單純的段落分隔，落在同一個源碼行內，不影響全文檢索。

二、字：缺字與梵文轉寫

辭典裡有兩類「顯示不出來」的字，處理方式完全不同，混在一起就會把正字當成缺字：

  • 組字式（如 [口*縛]）是 CBETA 用來表示一個漢字缺字的構成描述，共 964 處， 其中 919 處依 165 種構成對照表直接換成正確漢字（[口*縛] → 嚩），剩 45 種構成查無對應正字，維持原樣並在表裡標「未決」。
  • CBDIA 羅馬轉寫記號（a%、n%、i^、v! 等）是「記號＋基字」的組合， 同一記號隨基字改變讀法：% 在母音上是長音（ā）、在子音上是點上（ṁ/ṅ）；^ 在母音上是長音、在 n 上變波浪（ñ）。 所以對照表必須以 (記號, 基字) 為鍵；6,936 處轉了 6,890 處（99.34%）為 Unicode 拼音字元。
  • 悉曇／種子字用 Unicode 悉曇段（U+11580–U+115BF），這是閱讀器認得的位置； U+87xx 一類是借來當容器的碼位，同一碼位在大正語料與丁福保語料所指不同，故絕不按碼位無差別替換。

留在表裡沒轉的 46 處不是偷工：或兩版連基字都不同（BAUS 寫 N!a、鏡像作 Ḍa）， 或鏡像自己以缺字圖片代 é/è，機械無從判定，一律不硬湊規則，逐條列在轉寫殘留清單裡。

三、修復的引用錯誤（附校勘表）

經文出處的鏈路是兩段式做的，這是作者定的方法：先拿引文去大正藏查候選頁，再用經名核對它挑的本經對不對。 核對這一環前後修掉五類錯誤，每一類都留下可覆核的表：

修掉的問題說明影響量
回指分支形同虛設題面「同經」「又」「本經」這類回指，程式先把引導字洗掉再判是否回指， 於是「同經」變成裸字「經」，回指分支永遠進不去——作者舉的例 「佛說阿彌陀經之異名。…同經曰：『汝等眾生…』」就一直在這種狀態。以回指字起頭 1,424 條，此前走回指 0 條；現判為回指 929 條（正文回溯 764、順序繼承 149）
單字經名造成的假通過「經」是任何書名的子串，舊比對讓它配上《佛說阿彌陀經》判成「一致」； 這是看起來對、其實沒核的那類。已規定兩邊少於兩字一律標「題名過短不可比」，單列不計功（26 條）
品名剝離攔腰截斷書名剝「法華經譬喻品→法華經」的規則尾巴是選填，結果凡含體裁字的長書名都從第一個體裁字鋦斷： 「法華經玄義」→法華經、「四分律刪繁補闕行事鈔」→四分律、「四十二章經」→四十二章。全庫 22,652 條題面，舊式剝 4,412 條、新式剝 2,272 條，2,140 條不再被截斷
注家代稱污染上下文「同天台疏」這類代稱被寫進「前文經名」，後面整串回指一起錯到一個語料裡沒有的書名上。受污染的繼承 301 行（帶錨點 111 個）；已拆開計數，閘門待作者定案後再開
異體字認不出丁福保寫「增一阿含經」，大正題「增壹阿含經」；「秘藏寶鑰」對「祕藏寶鑰」。 這類不是簡繁轉換，是逐對異體。異寫表 4 對；注家·省稱對照 22 條（止觀→摩訶止觀、輔行→止觀輔行傳弘決、玄應音義→一切經音義…）
簡稱展開「法華經」是「妙法蓮華經」的跳字子序列，不是連續子串，用子串比會把正確鏈判成不符； 一对多的（如「智度論」）標為歧義，不硬選一部。題名對照 4,628 條；書名底表 4,108 部

鏈路總量與去留：引文 27,024 筆 → 大正候選錨點 14,235 個 → 經名核對剔除 3,158（經名不符 2,824、候選超過 100 家的短通用引文等） → 保留 11,077 → 實際發射字元級錨點 10,577 個（其餘是同一行內兩段引文重疊，共用一個錨點）。 「候選 > 100」這一刀是刻意留的：一句「一切眾生悉有佛性」在藏裡到處都是，位置基本靠猜，寧可不鏈。

四、驗收與對賬

每次建置都跑同一組硬檢查，任何一項的樣本數為零即視為失敗（這個坑踩過：拿掉標籤後的純文字去數詞條行，數到 0 卻報「通過」）：

  • 詞條實數 31,585 ＝ <詞> 行 ＝ 詞條索引實例，且逐位對齊 0 偏移——這三者不對齊時閱讀器會靜默退化成全文搜尋，表面看不出問題。
  • <聯 n=> 2,724 種目標，不在詞條索引者 0（零死鏈）；同形詞頭序號連續。
  • 31,585 條逐條回讀比對內容（兩側套同一張正規化規則）：不符 0；詞頭與源逐條相等。
  • 版面：詞條必在行首、<段/> 不落行首／不嵌在標記內／後面必接義項序號、標記成對——六項皆 0。
  • 母區閱讀端測試 17 項通過（詞頭色塊走的是既有 <例> 配色通道，不影響既有庫）。

另外做一層獨立對賬，不只引用打包工具的自報數：實讀行數＝庫總行數、庫內錨點數＝打包驗收、 保留集＝由逐條判定檔重算、501 個重疊丟棄按「段自身性質」重分類、照發射邏輯模擬一遍得 10,576＋跨標記重發 1＝庫內 10,577、 開閉標記配對。六項互相咬合才算數。

六、已知缺口（不藏）

  • entryid 16755 仍缺（悉曇／種子條）。根因是站端 IIS 腳本逾時 ASP 0113 Script timed out， 把逾時放到 300 秒會回 HTTP 500 錯誤頁，與網路無關；同一批另四條已從 CBETA 系來源補齊並記在補錄表。
  • 45 個組字式、46 處轉寫無法機械判定，維持原樣並列在表內。
  • 卍續藏尚未發鏈：本版所有字元級連結只指向大正藏（taisho.adb）。查卍續藏請另開 wxzj.adb 的全文檢索。
  • 「同天台疏」這類引導詞＋注家專名仍當書名處理，未收進對照表——它隨前文所論經而指不同書，靜態映射必錯。
  • 玄應《一切經音義》與慧琳《一切經音義》在大正書名層同名，靠書名無法區分兩家（實測受影響 1 條）。
  • 大正連結是「查得到出處」，不保證與丁福保引文同文：辭典常有節錄、改字與異文。詞典本文一律照 BAUS 原樣， 不按大正擅改；要校異文請查 CBETA 的 P5 校勘記。

原料與建置腳本、逐條校勘表與可重跑的驗收／對賬腳本，都在 dfbdict（建庫端）與 fodict（抓取端與校勘表）。 發現錯字、漏條或鏈錯本經，歡迎到聯絡頁留言，請附詞條名與頁碼，便於逐條覆核。
