fgdict.adb 製作說明（佛光大辭典）

《佛光大辭典》1995 年光盤版 XML 的 accelon26 重建版，7 冊、6,984 頁、22,648 個詞頭。 本庫的重點不是把辭典重新打字，而是把被前人丟失的原書頁碼、欄位、直行找回來， 讓有原書的人可以在閱讀器裡逐頁、逐欄、逐行查核。

項目內容
詞條22,648 個詞頭實例；唯一詞頭 22,646 個（乳糜、淨土各重複一次）
原書結構7 冊、6,984 頁、每頁常態 3 欄、每欄常態 20 直行；詞條自成一行，正文行保留 <行 n>
資料來源1995 年《佛光大辭典》光盤版導出 XML；有光盤者可依 GitHub fgdict 腳本重現
授權與下載限制僅限已擁有《佛光大辭典》任一版本（含紙本書、光盤版或其他正式版本）之使用者下載與研究使用；下載即表示確認符合此條件。加工程式碼、新增標記、校勘表與文件以 Creative Commons Zero（CC0） 釋出；《佛光大辭典》本文權利仍屬原著作權人，不因 CC0 而授權未擁有原書者再散布原文。
搭配使用同頁的 taisho.adb（大正藏）與 wxzj.adb（卍續藏）可讓辭典中的經文出處直接跳過去；若另有 goryeo_taisho.adb，可搭配高麗藏⇄大正藏位置對應表查看不同版本位置。
檔案fgdict.adb，27.9 MiB（本機 D:ccelon3 那份為準，線上以清單顯示的大小／日期為準）

一、恢復原書換行

1995 年電子檔原本有硬換行，但後續技術處理把逐頁、逐欄、逐行對應丟失了。本庫依原始 XML 重建：

  • 一行＝原書一直行：ADB 內每一行對應原書一直行。
  • 詞條自成一行：<詞>一切智無所畏</詞> 不與正文混在同一行。
  • 頁 id 可查核：不帶 p、不補零，例如 1a、3198c；重複頁如 3174_2a，4 欄以上如 1132x4。
  • 行號保留：<行 n="7"/> 放在正文行，方便有原書者按頁欄行查。

三、大正引址是位置入口

《佛光大辭典》為了方便查找，常只給出大正藏位置；但校勘檢查顯示，詞典引文有時候跟的不是 大正藏「大」字本文，而是宋、元、明、宮、流布、思溪等版本異文。

詞典大正藏位置大正藏本文校勘
一者為蛇虫故taisho?24p919b一者為地虫故地【大】，蛇【宋】【元】【明】【宮】
恢廓廣大taisho?12p269c開廓廣大開【大】，恢【流布本】
旋遶世尊taisho?12p12b旋繞世尊大正原本作「遶」；CBETA／元本作「繞」
人各搯珠taisho?50p593c人各掐珠大正原本作「搯」；CBETA／麗本作「掐」

處理原則：不擅自把詞典改成大正藏本文。連結仍跳到詞典給出的位置；異文、增省、錯頁、 改寫一律列入考据報告與待處理清單。

四、校勘表與待處理清單

目前 350 條跨行大正補鏈中，320 條已加 q/j；其餘 30 條逐筆分類：

  • 12 條可判定為異文／異體字差異。
  • 4 條為引文邊界、增字、省字或合敘。
  • 4 條為錯頁或他頁可尋。
  • 7 條在大正藏找不到對應段。
  • 3 條無引文可查，屬 q/j 擷取器待改善。

完整檔案在 GitHub fgdict：

  • docs/TEXTUAL-COLLATION-REPORT.md：考据報告。
  • out/taisho-nonvariant-backlog.csv：18 筆非異文待處理清單。
  • out/taisho-partial-diff.md：partial_text 逐字對照。
  • out/taisho-variant-count.md：異文統計。

五、重建流程

python scripts/page_registry.py
python scripts/build_model.py
python scripts/build_glossary.py
bun scripts/build_fgdict.ts
run_tests.bat

正式成品輸出 fgdict.adb。原始光盤與掃描圖不隨本倉庫散布；有原書者可依上述腳本重建。

六、已知限制

  • 本庫僅供已擁有《佛光大辭典》任一版本者研究使用。
  • 卍續藏仍有 ambiguous／weak／unresolved 待複核。
  • 詞條級外語已標記；行內級外語尚未全部納入 glossary。
  • 部分大正 q/j 因引文邊界、錯頁或找不到對應段而尚未補齊。
