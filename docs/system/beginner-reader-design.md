# 初學者讀經器（精讀模式）設計草案

> 2026-11-03，從作者口述整理。**本文只定方向與取捨**，實作細節在動工時補。
> 參考對象：accelon26 的編輯模式（CodeMirror 6 ＋ 語法高亮）與右欄分頁的寫法。

## 0. 一句話

在 accelon26 主畫面加一個**精讀模式**（比照編輯模式）：左邊 70% 是可標注的經文頁
（CodeMirror 6，ruby 注音＋語法高亮），右邊側欄之後變成主畫面右欄的「精讀」頁籤。
兩種學習路徑——**漢文讀者學原詞**、**巴利讀者學詞義**。

## 1. 目標與非目標

目標

- 初學者「看得到一個詞的來歷」：名詞／巴利詞上方有 ruby，內容可選（梵、巴、藏、漢、英、日…）。
- 兩種模式（§2），共用同一套頁面與抽屜。
- 與 adb 直接接：開發時起本機 server（`ts/tools/serve-adb.ts`），不必每次重打包 HTML。

非目標（現階段刻意不做）

- **大正藏「冊頁行字」定位**——之後再說；本器先用 `塊.段:句`（`docs/adb/sentence-align-container.md`）。
- 編輯／改稿（編輯模式已有）。
- 詞對齊演算法（sz 在做；本器只消費結果）。

## 2. 兩種模式

| 模式 | 讀者 | 經文 | ruby 放什麼 | 資料來源 |
|---|---|---|---|---|
| **A 漢文精讀** | 熟悉中文、想學原詞 | 心經、金剛經、阿含 | 漢詞上方的梵／巴原詞 | `glossary` 容器、`<术 sk/pi/tb>`、`data/terms.tsv` |
| **B 巴利精讀** | 學巴利 | 巴利原文（cs）與譯本 | 巴利詞上方，使用者**自選語言**（漢／英／日…） | `lex.adb` 的釋義、`align` 容器（詞／句對齊） |

共通（作者 2026-11-03 定案）：

- **ruby 一律在字的上方**（真 ruby 排版，不是行內括號）；為了不壓到下一行，**行距要放大**；
  ruby 字級約為本文的 **75%–80%**。
- **一次只顯示一種語言**（漢、梵、巴、藏、英、日…擇一），用一個語言切換器換；
  不做多語同時顯示。
- **hover 顯示部分資訊**（詞形／簡要釋義）；**點一下在右側展開**完整詞卡
  （沿用 `lex-pane`：詞形、格位、詞件、例句）。

## 3. 版面

```text
┌─────────────────────────────────────────────┬──────────────────┐
│ toolbar：現在這部經 ＋ 語言切換（一行、短）  │  精讀頁籤        │
├─────────────────────────────────────────────┤  （hover 簡要；  │
│ 精讀頁（CM6）：上方 ruby＋語法高亮，左 70%   │   點一下展開     │
│ 行距比正文大（ruby 佔上方空間）              │   詞卡）         │
└─────────────────────────────────────────────┴──────────────────┘
```

- 選經**用 accelon26 既有的目錄樹**（作者 2026-11-03 定案），toolbar 不再做第二套選經 UI。
- 左 70%／右 30%；窄視窗把右欄改成 bottom sheet（與 `lex-pane` 的規則一致）。
- **直接做在 accelon26 裡，不另做 MVP**（作者 2026-11-03）：右側欄就是主畫面右欄的
  「精讀」頁籤，同一份渲染與事件，不寫兩套。
- 行高：ruby 行要比一般正文高（ruby 佔上方空間），行距由 CSS 變數控制，跟主題一致。

## 4. 為什麼用 CodeMirror 6

1. **編輯模式已經有**：`ts/src/vendor/codemirror/codemirror.js`（`window.CM`，
   由 `ts/tools/build-codemirror.ts` 打包，viewer 不直接 import npm），入口是
   `editor.ts: mountPageEditor()`。精讀模式可以照同一個模式做 `mountReadingView()`。
2. **ruby 是 decoration，不是字串拼 HTML**：CM6 的 widget／mark decoration 可以掛在
   指定 range 上，選取、捲動、換行都不會被破壞；手寫 `<ruby>` 拼 innerHTML 會在
   換行與塗紅時出錯（我們在 `render_accelon3` 已經吃過這種苦）。
3. **語法高亮**：CM6 的 `Decoration`＋`ViewPlugin` 就夠（不需要 Lezer 文法）；
   要分「標題／正文／詞／註」時，用同一套 highlight 標記。
4. 游標、選取、搜尋、複製都是內建，不必自己維護。

## 5. 資料與位址

- 經文：adb 的 `source` 一行一行取（與現在 `doc-pane` 相同），行號即 `句`。
- 詞對齊：
  - A 模式：`glossary`（漢詞→梵／巴）＋ `<术>` 標記；缺的詞先不顯示 ruby，不要猜。
  - B 模式：優先 `align` 容器（詞／句對齊）；沒有 `align` 就退回 `lex.adb` 的釋義。
- **巴利譯本可以插入不可見空格**（U+200B）分詞：該庫的 VA 不重要、隨時可重建，
  所以「一個詞一個單位」可以直接寫進文字，不必等索引。
- **詞對齊完成後，以漢詞作分詞基礎**：漢譯端的「詞」以漢詞為單位（不是逐字）；
  巴利端仍以詞為單位。這件事等 sz 的詞對齊有結果再做，先留接口。

## 6. 邊界（先寫下來，免得日後誤會）

- 巴利譯本插入 U+200B 會增加 token 數 → 該庫重建後 VA 會變；**只限「VA 不重要」的庫**，
  `cs`（對齊母本）與大正藏不要動。
- 大正藏用「冊頁行字」，等本器站穩再談（那時才需要 page/column/line 三層）。
- 精讀頁**不改正文**：所有標注都是顯示層（decoration），存檔／匯出不帶 ruby。

## 7. 里程碑（直接做在 accelon26，不另做 MVP）

| 階段 | 內容 | 驗收 |
|---|---|---|
| M1 | 主畫面多一個「精讀」模式（CM6 精讀頁讀 adb、toolbar 選經） | 開一個 adb、選一部經、捲動正常 |
| M2 | A 模式：漢詞 ruby 梵／巴（上方 ruby、行距放大、字級 75–80%） | 心經／金剛經各一頁看得出來 |
| M3 | B 模式：巴利詞 ruby 自選語言（lex／align），一次一種 | 一段經文可切換漢／英／日 |
| M4 | 右欄就是「精讀」頁籤；hover 簡要、點一下展開 lex-pane | 主畫面可用、窄視窗 bottom sheet |
| M5 | 開發流程：`tools/dev-serve.ts`（每次重整重新建置、自動開上次的 adb）＋回歸測試 | 一條指令起 server、改了就看到 |
