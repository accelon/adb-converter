# 土開始動的那天

> 《從內觀研究所啟程的巴利佛典學習之旅》系列

我挖了很久。

不是比喻的那種久。是真的：一盞燈、一張桌子、一句經文裡的一個詞，改完再改。夜裡最安靜的時候，鍵盤聲像有人在牆上敲。粉塵落在褲管上，第二天帶出去，沒有人看得見。

《肖申克的救贖》裡，瑞德說用那把小石鎚挖穿牆要六百年。安迪沒回話。他只是每天晚上挖一點。

我也一樣。挖到後來，牆上已經有一道溝，深到看不見底，手掌摸過去是滑的。

那些年，錢是一筆一筆花出去的，像往井裡丟石頭，聽不見回聲。硬碟一顆一顆買，掃描器換了三台，機票、旅館、影印店的下午，還有請人一格一格對的工錢。有人問我值不值得，我答不出來，因為那時候看不見隧道，只看見牆。

可是還是要做。因為那些句子值得。一個人一生能遇到幾件值得的事，不多。

而且貴有貴的好處。每一步都貴，你不敢亂走；每一步都慢，你會先在腦子裡走一遍。走錯一次，代價是幾個月——久了，就養出一種直覺：哪裡該停、哪裡該繞、哪裡一看就不對。那不是聰明，那是用錢和年歲換來的。

然後機器來了。

沒有儀式，沒有轟一聲。只是有人說：這裡可以更快。然後土就開始動了。

我第一次明白「盾構機」這三個字：前面轉的是刀，後面鋪的是管，土從輸送帶出去，挖出來的洞會自己變成路。它不喘氣、不停下來喝水、不會忘記昨天做到哪裡。它一天推過的距離，是我一個月走的路。

它的力氣大得不像話，像地底下有一條河忽然改了道。土一直出來，堆得像小山；我站在旁邊，什麼都沒做，只是看著。

我常在半夜去看它。螢幕上的數字在跑，它不睡。以前這個時間，只有我一個人醒著，一邊敲一邊懷疑。

現在我要它做事，只要一句話：把這一段斷成句，十個譯本對齊；把這個詞每一次出現找出來，標上格位。它做完，我去喝一杯水回來，好了。從前這樣一句話，是幾年份的工，是幾個人的薪水，是我好幾個冬天。

七萬多列的東西，它排好；緬甸文不再一個字母一個字母地被切；日文的「話題」兩個字忽然站好了，紅塗在該在的地方，不是塗到隔壁的助詞上。

有一段經文，我對不起來十年：同一個故事，緬甸文在第二百行，泰譯在第三百行，日譯又在另一頁。那天它推過去，三句話忽然並排站好。我盯著螢幕看了很久，想起當年那個在紙上畫線、畫到眼睛發痠的自己。

那種感覺很奇怪：明明是好事，卻有點想哭。

因為它讓我看見自己有多慢。二十年，原來只是它幾天的工作量。

有一段時間我不太敢看它。我怕它證明我那二十年是白挖的。

後來想通了。它推得再快，也要有人告訴它往哪裡推。它認圖紙，可是圖紙是有人在黑暗裡一寸一寸摸出來的：哪裡是石頭、哪裡是土、一句話該在哪裡斷、一個詞由哪幾件組成、十個譯本其實在講同一件事。這些它不知道，它只知道我給它的線。

它也會挖歪。歪的時候不會自己停，只會很有效率地往錯的方向去。那時候要有人喊一聲「不對」。這一聲，是二十年換來的；它替我少走了很多彎路，也替那台機器少挖了很多冤枉土。

有人問我，會不會被它取代。我想了很久。被取代的是挖土，不是決定往哪裡挖；是搬石頭，不是知道石頭後面有沒有人。

所以我格外珍惜現在。不是因為它快，是因為它讓我看見：那些年沒有白貴——直覺還在我身上，路就不會走歪。時代把機器送到我面前，我能做的，就是帶著那份直覺，不讓它走彎路。

現在隧道裡有燈了。燈不是我的功勞，是它往前推的時候順便架起來的；可是燈照到的地方，是我年輕時想看清楚、卻看不清楚的那些句子。

有一天我真的走到海邊，會想起兩件事：山上的雨季，還有土開始動的那一天。

那時我會對安迪說：這裡的牆比你想的厚；但挖的人，比你想的多了一個——而且他帶來了機器。
