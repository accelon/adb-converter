# Accelon26 閱讀器

> 同一份單檔 HTML 同時服務瀏覽器與桌面 Wails 宿主。
> 桌面宿主另外提供檔案系統、下載與更新；閱讀器 UI 本身兩邊共用。

## 1. 定位

```text
Accelon3 的跨平台平替
直接讀 .adb
單檔 HTML（build/accelon26.html）
桌面版把同一份 HTML 包進 Wails
```

## 2. 入口

```text
建置：bun run tools/build-viewer.ts
輸出：build/accelon26.html
桌面：bun run tools/build-desktop.ts → wails/assets/index.html
```

開啟：

```text
file:///…/accelon26.html  → 選 .adb
或桌面 accelon26.exe
```

第一次使用（還沒有任何 adb）：本文區顯示引導卡「開始閱讀」，兩個按鈕
「⬇ 下載公開資料庫」（桌面版；開 `adb-store` 對話框）與「📂 開啟本機 .adb」；
網頁版只留後者。下載會寫到 exe 旁邊，📁 清單自動更新。`#dbHint` 也改成
「← 按 📁 下載或開啟資料庫」（2026-10-30）。

## 3. 目錄

上方資料庫晶片（`dbChip`）顯示**短名**：`taisho` → 大正、`wxzj` → 卍續、`goryeo` → 高麗、
`ys` → 印順、`tx` → 太虛、`lc` → 呂澂（2026-10-30）。短名的來源依序是
`<集 b="印順">…</集>` 的 `b=`（下次 rebuild 後才有）、上面的缺省表、最後才是庫名；
下拉清單的完整庫名（`.dbPickName`）不變。

左欄每一棵 `<樹>` 一個 pane：

- `s="*"`：目錄樹
- `s="$書"`：書名
- `s="*詞"`：全文
- `s="*u=…"`：頻次
- `m="taisho"`／`m="goryeo"`：高麗⇄大正（換算位置）

多個 `s="*"` 時，目錄上方出現樹選擇器；不是並排分頁。

搜尋後，目錄節點旁會出現命中數（紅字 `tCount`）。**點節點名稱或那個紅數字，會直接跳到該節點的
第一筆命中**（2026-10-31）：右欄摘要同時顯示這個節點的命中，本文跳到第一張卡的位置並塗色——
以前要「點紅數字 → 到摘要再點一次」兩步。範圍內沒有命中時只跳到節點起點。

### 3.1 study 的目錄

`taisho-study.adb` 只有一棵 `t="書"` 樹；每本書用 `t=` 宣告自己的下一層：

```text
<書 id="n2" t="品.">妙法蓮華經</書>
```

所以：

```text
大正藏研究 → 書 → 品／分
```

不再為每部經開一棵全域樹。

### 3.2 高麗⇄大正（`m="taisho"`）

`goryeo_taisho.adb` 帶兩藏逐字對照表，檔頭宣告：

```text
<隱><樹 m="taisho">高麗⇄大正</樹></隱>
```

- `m=` 的值是預設來源側，分頁名取 `<樹>` 的文字。
- 空著不顯示清單，只顯示說明：
  - 文字 → 找經名；數字 → 找經號（大正、高麗一起找）；`T`／`K` 前綴只找那一藏；
    `1.2` = 第 1 經第 2 卷；也可以貼位置（`T05p0002c0405`）或選取選單複製的
    字元級位置（`taisho?5p2c j=2-8`）。
- 清單一經一筆，例如輸入 `1`：

  ```text
  大般若波羅蜜多經 卷1   [大正]
  長阿含經 卷1           [高麗]
  ```

  - 每一筆前面有一個圈字，表示經名與卷從哪一藏來：**大正＝白底紅字、高麗＝藍底紅字**
    （`border:0`，2026-10-30）；右邊那顆是**要去的那一藏**。
  - **按經名**（圈字那一藏）就切到那一藏；**按右邊那顆**則去另一藏（對照），都在中間開啟（`openInMain`）。
  - 位置查詢時，右邊那顆就是位置所在的那一藏；字元級位置會順便把 `j` 指到的字塗色帶。
  - 位置只在滑過時以 tooltip 顯示；位址查詢顯示**字元級**（`T05p0002c0405 ⇄ K01p0004c2202`），不占列高。
    `-0507` 這種範圍會顯示起訖（`…0405 → …0507 ⇄ …2202 → …2307`）；`-0003a` 只給頁＋欄，
    表示到那一欄尾；`-` 後面不能跨冊。按下去時本文會跳到該位置，並把那一行（範圍就那幾行）
    塗上 `jumpHit` 色帶。
- 圖版不在這一欄：需要看圖版時，在經文裡選取，用選取選單的「查看 → 看大正藏／高麗藏圖版」。
- 沒有 `goryeo_taisho.adb` 時，這個分頁不出現，其他庫的選取選單也沒有高麗藏圖版。
- 換址不需要經文；`goryeo_taisho.adb` 只有兩行文字。詳見
  [goryeo-steps.md](../adb/goryeo-steps.md)。

### 3.3 全文搜尋（左欄輸入框）

輸入詞即時搜尋（120ms 去抖），結果在右欄「摘要」。**按 Enter 直接跳到第一筆**（2026-10-31）：
Enter 先跑完這次查詢，再點第一張摘要卡（開本文、塗色、把它設為 active），不必再用滑鼠點。
同一個查詢再按一次 Enter 不會重跑，仍停在第一筆；沒有結果時狀態列顯示「沒有結果」。

- **點摘要卡**（2026-11-01）：預設**開新本文分頁**，不會蓋掉目前從目錄打開的閱讀頁；
  同一張卡再點一次（沒有 Ctrl）沿用剛剛那個分頁；**按住 Ctrl/⌘ 一律再開新分頁**。
- **每個 adb 有自己的摘要**（2026-11-01）：切換 adb 時右欄會換回那個庫上一次的搜尋結果
  （含關鍵字顏色）；沒有查詢就清空，不會殘留上一個庫的摘要。
- **共享本文分頁（docTab）**（2026-11-01，設置 → 閱讀，預設關）：開啟後所有 adb 共用
  同一條本文分頁；每個分頁記住自己的庫。**點別庫的分頁只換本文，不換 adb**（左欄目錄、
  摘要、dbChip 都不動；那種分頁的麵包屑改顯示「本文來自《庫名》」＋一顆 🌲）；
  要把 adb 切到分頁所屬的庫，按 header 的 **🌲（在目錄中顯示目前位置）**。
  關閉時每個庫各自一組分頁（原本行為，切庫整組換掉）。
- `#123`／`#L123` 是跳行，Enter 才生效（打字時不查）。
- 用輸入框內建的 ✕ 清空；Esc 離開輸入框但不清字。
- **頁行引用**（2026-11-01）：`y38p7a8` ＝ ys 第 38 部書第 7 頁 a 欄第 8 行；少了 `a8` 是頁首
  （`y38p7`）、少了 `p7` 是書首（`y38`）。fuyan 沒有分欄，一律當 a 欄（`f1p7a3`）。
  前綴可以用庫名開頭（`y`／`f`／`t`）或全名（`ys38p7a8`）；全形、大小寫都可以。
  同一頁的 a/b/c 欄算**一頁**。搜尋框右側會顯示「頁行」，跳過去會把那一行塗成色帶。
  **庫名本身帶數字就寫全名**：yl38p24＝yl38 的第 24 頁（不會被當成「yl 的第 38 部書」）；
  整串剛好是現成的頁 id 時（yl38p24 就是 yl38 的頁 id），照頁 id 直接跳那一頁。
- 這裡只搜**目前這個庫**；跨庫用 Alt+S「搜尋所有 adb」（見 §3.4）。

### 3.3.1 腳注（`<註>`／`<釋>`）

- hover `[n]` 顯示那條 `釋` 的文字；點 `[n]` 跳到釋文；點釋文開頭的 `[n]` 跳回正文的 `註`。
- **同一個 n 在不同節是不同的注**（yl38 每節重新編號，`n=45` 有 9 條）：`<註>`／`<釋>` 都帶頁 id
  （`pg="yl38p24"`），配對順序是「**pg 相同 → 同頁最近 → 頁碼最近**」；沒有 pg 的庫（ys／taisho／
  fuyan）自動退化到後兩條，行為不變。**hover 與點擊走同一個解析函式**，所以兩邊一定落在同一條（2026-11-01 定案）。
- `<釋 n="1"/>` 標籤自成一行、注文在後面的寫法也支援（往後多找幾行）。

### 3.4 搜尋所有 adb（Alt+S／放大鏡）：索引、單庫萬用、全庫萬用

對話盒上方三選一（記住上次的選擇）：

| 模式 | 用途 |
|---|---|
| **索引**（預設） | 一般查詞。逐庫用 token 索引查，一個庫查完就更新一次清單，最後按命中數排。點一列打開該庫並把查詢帶進左欄。 |
| **單庫萬用** | 只掃目前打開的那一庫。 |
| **全庫萬用** | 掃清單上的每一庫（慢，但有進度、可中斷）。 |

**萬用字元語法**（只比對漢字，不使用 regex）：

- `？`＝**恰好一個漢字**（`？？`＝兩個）。
- `＊`＝**1–4 個漢字**（不提供「不特定長度」）。
- 其他字元照字面比對（標點、數字、拉丁字母都可以）。
- **至少要有一個字**：單獨的 `？`／`＊`／`？？` 會被拒絕（那等於列出全部）。
- 不支援 `.` `[` `]` `(` `)` `|` `+` `^` `$` `\`——`？`／`＊` 就是你要的「任意漢字」。
- 例：`？象`（象前面一個字）、`白＊心`（白＋1–4 字＋心）、`＊心`（心前面 1–4 字）。

**掃描**會先用樣式裡的漢字查索引，只解壓可能命中的段落，所以比全檔掃快很多，
但大庫仍要幾秒到幾十秒：畫面有一條進度條，顯示**已掃／剩餘／找到幾筆（幾種字串）**與
已用秒數，右邊的**中斷**鈕隨時可以停。跑完之後列出的不只是每個庫的命中數，還有
**命中的字串**（次數多的在前，點一下打開該庫跳到第一次出現）——研究上要看的正是
「某字前後可能出現哪些字」。

> 實測（`tools/wildcard-scan-cli.ts`，taisho 331 MB）：`？象` 掃 5,688 / 15,433 段、
> 42.8 M 字，約 11 秒，命中 16,806 筆／1,148 種字串；
> 前五名是 香象 1,085、**白象 1,000**、龍象 872、萬象 867、大象 737。

## 4. 注疏

`<嵌>` 晶片：

```text
<嵌 i="taisho?18p24b" j="210-237" t="…" n="1 家注疏"/>
```

- 點晶片：右欄展開注疏群
- `大正↗`：右欄開母庫目標頁並塗紅（**Ctrl/⌘+點**：切到那個庫，在中間開啟）
- 右欄的跨庫分頁也可以 **Ctrl/⌘+點**：切到那個庫，在中間開啟同一頁（2026-10-30）
- `study`／`jingang` 是終點庫，不顯示「引用複製」

study 另外有 `study/index` block 的注疏清單：

- 標題列「注疏」按鈕
- 只在有 study 庫時顯示
- 同時開 `taisho.adb` 也不消失
- 按下去切回 study 並開清單

詳見 [taisho-study.md](../adb/taisho-study.md)。

## 5. 選取選單

選取本文後出現的浮動選單是**兩層**（2026-10-30）：第一層三組（**複製／搜尋／查看**），
滑過或點一下就在右邊展開第二層。

| 第一層 | 第二層 |
|---|---|
| **複製** | **引用複製**／**複製文字**／融入引用／嵌入引用／**複製字元級位置**／（大正藏、高麗藏）**複製高麗⇄大正位址** |
| **搜尋** | 這個庫現在有、而且能接受輸入的左欄分頁：目錄／名詞／頻次／原書分頁／西文／高麗⇄大正（名稱取自分頁標題）。點一個就把選取文字送進去、並切到那一頁。沒有樹的庫才有「跳至」；有樹時頁 id／位置語法直接在目錄搜尋框輸入（見 §5.1）。 |
| **查看** | 查字典／開《…》（選到經名時）／看大正藏圖版／看高麗藏圖版 |

底下另有一行「☆ 加入書籤」（保留原本的書籤功能）。

- **字元級位置**：`資料庫?頁 id j=起-止`，例 `taisho?5p2c j=12-34`（`j` 是這一頁第幾個漢字，
  起止都包含；沒有 `<頁>` 的庫用行號 `L123`）。區段跨頁時只記到起始頁。
- **高麗⇄大正位址**：兩側的 posmap 位址範圍，例 `T05p0002c0405-T05p0002c0612`；
  只在大正藏／高麗藏、而且對照表載入時出現（貼進「高麗⇄大正」的輸入框就能查）。
- 終點庫（`jingang`／`study`）不顯示「引用複製」。

study 中選到可辨識的大正頁碼：

```text
18p14c
8p748c
T18n0890_p0014c
```

選單只留「查看→打開經文」與「複製→複製文字」。
「打開經文」需要母庫 [taisho.adb](../adb/taisho.md) 已開。

讀大正藏或高麗藏時，「查看」裡有（2026-10-30）：

```text
看大正藏圖版     DIA：index.html?id=Tv05p0002#?c=0&m=0&s=0&cv=10&xywh=0%2C1783%2C2236%2C837
看高麗藏圖版     KABC：dataId=ABC_IT_K0647_T_001&imgId=017_0815_a
```

- 大正藏圖版只需冊與頁，讀 `taisho.adb` 就有；**hash 會指到選取所在的欄**
  （a／b／c = 上／中／下欄）：
  - `#?c=0&m=0&s=0&cv=10&xywh=0%2C<y>%2C2236%2C837`
  - `w=2236`、`h=837` 是 1080p 下一欄的大小；`y` 取三等分：a=214、b=1001、c=1783；x 固定 0。
- 高麗藏圖版需要經號、卷、冊、頁、欄；要有 `goryeo_taisho.adb` 的對照表才顯示。
- 目前只把網址交給系統瀏覽器，不在閱讀器裡顯示圖版。

### 5.1 跳至接受字元級位置（2026-11-01：分頁取消，併入搜尋框）

「跳至」不再是左欄的一個分頁：只要資料庫有樹，功能就併進**第一個目錄樹**的搜尋框
（`#query`）。把「複製字元級位置」的字串（`taisho?5p2c j=12-34`）貼進去按 Enter：

- **先當全文搜尋**；搜尋找不到時，才判讀「跳至」可接受的語法（頁 id、大正藏引用、
  字元級位置）。找得到就跳，找不到才顯示「沒有結果」。
- 如果字串指的庫不是現在這個，會**切回那個庫**（已開的分頁；網頁版要先開過）。
- 跳到那一頁，並只用 CSS Custom Highlight（`::highlight(accelonCharBand)`）把
  `j` 指到的**那幾個字**塗色帶（不是整行）；重畫或換頁就清掉。
- 手寫 `taisho?5p2c j=0-4` 也可以；純頁 id（`49p15`、`8p848c`）直接跳到那一頁。
- **目錄路徑**（2026-11-01）：`1.2.3` ＝第 1 書 → 第 2 章 → 第 3 節，依左欄 TOC 結構計數，
  不是解析標題文字。`序`／`前言`／`自序` 算 **0**（`1.0.1` ＝第 1 書序裡第 1 節）；
  同層沒有編號的節點照 TOC 順序接在後面；中文數字與阿拉伯數字等價（`一.三.一` ＝ `1.3.1`）。
  `.` 與 `-` 可以混用，但**至少兩組數字**才觸發路徑模式。
  **路徑模式不跑全文搜尋**（不顯示摘要、不塗關鍵字）：輸入時就切到路徑模式，
  按 Enter 直接跳到該節點並連動本文；若之前有搜尋結果會先清掉。
  只寫到前面幾層也可以（`2.3`）；單獨一個數字（`2`）不算路徑，仍走全文搜尋。
  成功會在狀態列顯示完整路徑；超出範圍會明說（例：`找不到 1.9.9（章只有 4 個）`）。
- **節點序號**（2026-11-01）：`1-3-4` 用連字號，表示同層節點的 **0 起算序號**，
  照 TOC 原順序（含序／前言與未編號節點），不看中文數字、也不做「序＝0」的重排；
  `.` 與 `-` 可混用，只要含 `-` 就整串走這個模式（`1.2-3` ＝ 1、2、3）。
  超出範圍照樣明說（例：`找不到 1-3-4（節只有 5 個，序號從 0 起算）`）。
- 完全沒有任何樹的資料庫，才會保留獨立的「跳至」分頁；不再顯示「共有幾頁」。
- 搜尋框空白停留 1.5 秒會出現「跳至」語法提示卡；卡片上的「不再提示」會關閉提示，
  之後可在 **設置 → 閱讀 → 輸入跳至提示** 重新開啟（預設開）。卡片內容依目前 adb
  調整：不是 taisho 就不顯示大正引用，頁 id 範例也換成該庫的（例 `05B-p008`）。

### 5.2 註文裡的多筆大正引用（2026-10-30）

同一個 `<釋>` 裡有 2 筆以上 `<聯 i="taisho?…">`（例如 ys 的註 37.085：1081a、1082c、1099c）時，
**每一筆都直接是可點的連結**（沒有下拉／選單）：注文的句子照原樣排，
「一二．一〇八一上」「一〇八二下」「一二．一〇九九下」各自連到目標頁。

- 只有 1 筆時也是同一種連結。
- 沒有 `q` 的聯只跳到目標頁、不塗色（不會報錯）。
- 點擊走 `xref.ts` 的 `a[data-xref]` 委派（和正文其他 `<聯>` 同一條路）；
  注文外框「點注文回註」會避開 `a[href]`，不會吃掉連結。

### 5.3 引文用楷體（2026-10-30）

CBETA 的 `<quote>「…」</quote>` 由 y2adb 轉成 `<引>「…」</引>`；閱讀器把 `<引>` 畫成
`.quote`，用楷體字堆（`--kai`：Kaiti TC／Kaiti SC／KaiTi／BiauKai／標楷體／DFKai-SB／
AR PL UKai），字級 `1.02em`，和作者自己的敘述分開。跨行的引文在行尾收掉、下一行重開，
HTML 每行都是平衡的。

要看到效果，該 adb 必須在建置時寫出 `<引>`（目前只有 ys.adb；其他 adb 要在自己的
轉換工具加同樣的映射）。

### 5.4 閱讀狀態（回報問題用，2026-11-01）

設置 → 進階 →「閱讀狀態」：填一個名稱（例如「編輯前」），按**匯出閱讀狀態**就會下載一份
JSON。檔名是「修訂者 ID＋本地時間」，例如 `sukhanika20261101150312.json`（ID 在「關於」設定；
沒有 ID 時用 `anon`）。

記下來的東西：開著的 adb（庫名＋dbname＋大小，**不記路徑**——adb 就跟執行檔放在一起）、
每一條本文分頁（庫／範圍／頁碼／釘選的命中／捲動位置）、
**目前本文的選取區**（行號＋行內第幾個漢字＋選到的文字，以及那一頁的開頭幾行）、
閱讀開關（原書分行／原書頁碼／繁簡／術語／字級）、介面狀態與診斷數字（搜尋詞、命中數、
目錄游標、pagerLog、dbLog）。

> 這一份是**手動**匯出的，和平時「離開 exe 自動記住」的那份無關：自動記住的只有開著的庫、
> 頁碼、捲動位置與選取區（存 localStorage）；這裡的 JSON 多了介面狀態與診斷數字，
> 是給作者重現問題用的。

**載入閱讀狀態…** 會把同一份狀態還原：開回同樣的庫、切到同樣的分頁與頁碼、把選取區重新選起來
（需要同樣的 adb：放在執行檔旁邊就會自己認出來，認的是**庫名／dbname／大小**，不是路徑；
找不到的庫會在狀態列列出）。主題、進階模式、標籤樣式不會被改
——那些是這台機器的偏好，不是閱讀狀態。

回報問題時把這個 JSON 一起給作者，他就能重現你看到的畫面。

## 6. 桌面專屬

- **啟動時恢復上次開著的 adb，以及上次看到的地方**（2026-11-01）：開著哪幾個庫、哪一個是
  active，以及**目前本文的捲動位置與選取區**，都在**離開 exe 之前存一次**
  （`localStorage['accelon26.openset.v1']` 與 `accelon26.lastRead.v1`；平時不寫）。
  下次啟動全部開回來（上限 5 個），各自回到上次那一頁、那個捲動位置，選取的字還選著。
  紀錄裡的檔找不到（搬走／刪掉）就跳過並在狀態列說明；全部關掉的狀態下不記，
  下次啟動仍會開一個（有 logo 的那個）。
  > 這些紀錄**不寫進 `settings.json`**：`settings.json` 是跟著程式跑的設定檔（會給別人看、搬來搬去），
  > 裡面只放跟機器無關的東西（標籤樣式、鏡像站）；adb 路徑留在各人自己的 localStorage。
- `📁` 下拉：`⬇ 取得更多 ADB`
- 下載／更新 adb 時，進度列顯示：百分比、已下載／總量、**網速**（KiB/s、MiB/s）
  與**預估剩餘時間**（`1時02分03秒`、`12分03秒`、`3秒`；速度用 300ms 窗做指數平均，
  避免數字亂跳，2026-10-31）
- 離線時該項變暗但不隱藏
- `＋ 加入 Obsidian` 只在進階模式
- Wails host 提供 `SaveAdb`、`StartNewAdbDownload`、mmap 讀取

詳見 [desktop.md](./desktop.md)。

## 9. 悉曇／蘭札字型

`taisho.adb` 的梵字是 Unicode 第 16 平面私用區（`SD-XXXX → U+FA000+XXXX`、
`RJ-XXXX → U+100000+XXXX`），系統字型沒有。閱讀器把 CBETA 的 Siddam／Ranjana
字型改寫 cmap、子集化後，以 data URI 內嵌進單檔 HTML（桌面版同樣內嵌），
所以不必安裝字型。設置（齒輪）多一頁「悉曇」，直接展示
`T21n1213_p0072b08` 與 `X23n0446_p0762b05` 兩段經文，沒有 `taisho.adb` 也看得到；
頁面可勾選在每個字形右邊顯示 IAST 轉寫。

細節（碼位對照、字型建置、授權）見 [siddham-ranjana.md](../adb/siddham-ranjana.md)。
