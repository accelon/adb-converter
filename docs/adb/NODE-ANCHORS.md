# 通用節點錨點（科判等結構節點）

> 2026-11-13。讓 `<科14 n="kpD14-020">` 這類**結構節點**也能像大正頁碼一樣被
> `anchorVa()`／`<嵌>` 定位；不改動頁 id 與 `塊.段` 的既有語義。

## 解析順序

`anchorVa(r, anchor)` 依序嘗試：

1. **頁 id**（`attributes/頁.id`，如 `30p328c`）
2. **塊.段[:句][#詞]**（`塊.id`＋`段.n`，如 `a6.7`、`rv.1.2.1`）
3. **通用節點錨點**（本文）

前兩者失敗才會進第 3 條；現有 taisho／13j／sz 等庫行為不變。

## 錨點標籤

- 取所有 `<樹 t="…">` 宣告到的**層級標籤**聯集（例 `t="篇,章,科01,…,科54."`），
  另加若有 `<錨>` 標籤。
- 節點值優先取 `n`，其次 `id`。

## 命名空間

- **篇級**：`W#值` 或 `W/值`（例 `T1579#kpD03-001`）。`W` 取「層級最多那條 `t=` 的第一個標籤」
  （ybh＝`篇`）的 `id`／`n`；沒有就取該節點標題最後一個括號內代碼（`（T1579）`）。
- **卷級**：`W-V#值`（例 `T1579-1#kpD03-001`）。`W-V` 取**第二層標籤**（ybh＝`章`）的
  `id`。此別名只在該標籤的 id **全域唯一**時啟用（避免其他庫的「章1、章2」跨著作撞號）。

## first / last 語義（寫死）

| 寫法 | 同值多處時取哪一筆 | 安全性 |
|---|---|---|
| 裸值 `kpD14-020` | **文件序第一筆**（最小 VA） | 多著作會撞號，僅適合單著作 |
| 篇級 `W#值` | **文件序最後一筆**（最大 VA） | 同作品多卷會撞號，**不安全**；只在該值全作品唯一時使用 |
| 卷級 `W-V#值` | 該章區間內唯一（精確） | **建議一律用這個** |

- 卷級命名空間若在該卷內找不到值 → 回 `null`（**不退回**篇級，避免指到別卷）。

## 節點範圍與 `<嵌>`

- `nodeAnchorInfo()` 回 `{va, vaEnd, tag, ns, value}`；`vaEnd`＝下一個結構節點的 VA。
- `<嵌 i="ybh?T1579-1#kpD03-001" n="出體"/>` 展開後＝節點標題＋其下內容（到下一個結構節點為止，預設上限 60 行）。
- 沒有 `<頁>` 的庫（ybh）也能嵌；不再因「沒有頁碼表」而失敗。

## 產生器建議

- `<篇>`／`<章>` 都給 `id`：篇＝`W`、章＝`W-V`（全域唯一）。
- 跨著作／跨卷引用一律用**卷級** `W-V#值`；篇級只在全作品唯一時使用。
