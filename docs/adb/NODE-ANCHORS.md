# 通用節點錨點（科判等結構節點）

> 2026-11-13。讓 `<科14 n="kpD14-020">` 這類**結構節點**也能像大正頁碼一樣被
> `anchorVa()`／`<嵌>` 定位；不改動頁 id 與 `塊.段` 的既有語義。

## 解析順序

`anchorVa(r, anchor)` 依序嘗試：

1. **頁 id**（`attributes/頁.id`，如 `30p328c`）
2. **塊.段[:句][#詞]**（`塊.id`＋`段.n`，如 `a6.7`、`rv.1.2.1`）
3. **通用節點錨點**（本文）

前兩者失敗才會進第 3 條；現有 taisho／13j／sz 等庫行為不變。

## 錨點標籤

- 取所有 `<樹 t="…">` 宣告到的**層級標籤**聯集（例 `t="篇,章,科01,…,科54."`），
  另加若有 `<錨>` 標籤。
- 節點值優先取 `n`，其次 `id`。

## 命名空間

- **篇級**：`W#值` 或 `W/值`（例 `T1579#kpD03-001`）。`W` 取「層級最多那條 `t=` 的第一個標籤」
  （ybh＝`篇`）的 `id`／`n`；沒有就取該節點標題最後一個括號內代碼（`（T1579）`）。
- **卷級**：`W-V#值`（例 `T1579-1#kpD03-001`）。`W-V` 取**第二層標籤**（ybh＝`章`）的
  `id`。此別名只在該標籤的 id **全域唯一**時啟用（避免其他庫的「章1、章2」跨著作撞號）。

## first / last 語義（寫死）

| 寫法 | 同值多處時取哪一筆 | 安全性 |
|---|---|---|
| 裸值 `kpD14-020` | **文件序第一筆**（最小 VA） | 多著作會撞號，僅適合單著作 |
| 篇級 `W#值` | **文件序最後一筆**（最大 VA） | 同作品多卷會撞號，**不安全**；只在該值全作品唯一時使用 |
| 卷級 `W-V#值` | 該章區間內唯一（精確） | **建議一律用這個** |

- 卷級命名空間若在該卷內找不到值 → 回 `null`（**不退回**篇級，避免指到別卷）。

## 節點範圍與 `<嵌>`

- `nodeAnchorInfo()` 回 `{va, vaEnd, tag, ns, value}`；`vaEnd`＝下一個結構節點的 VA。
- `nodeSubtreeEnd(r, va)`（2026-11-13）：沿錨點序往後找**下一個同層或更淺**的節點（層序取自樹 `t=` 宣告次序），即整棵子樹的排他界；子孫一路到底沒有兄弟時回 null（到檔尾）。
- `<嵌 i="ybh?T1579-1#kpD03-001" n="出體"/>` 展開後＝節點標題＋其下內容（到下一個結構節點為止，預設上限 60 行）。
- `<嵌 … sub="1" max="N"/>`：`sub="1"` 取**整棵子樹**（界＝`nodeSubtreeEnd`），行數上限預設 200、`max` 可覆寫；不帶 `sub` 時行為與舊版完全相同。
- 沒有 `<頁>` 的庫（ybh）也能嵌；不再因「沒有頁碼表」而失敗。

## `<節聯>`（2026-11-13）

`<節聯 n="T1579-1#kpD03-001">問答標列</節聯>` ＝「點一下捲動過去」，與 `<嵌>`（就地展開）、`<聯 n=>`（字典條目）三分工：

- 屬性：`n=` 同庫錨點；`i="db?anchor"` 跨庫（拆出 db）。`newtab="1"` 或 Ctrl/⌘ 點擊＝新分頁。
- 目標可寫任何 `anchorVa` 認得的形式（頁 id／塊.段／節點錨點），不限 kpD。
- 渲染：`<a class="entryLink nodeLink" data-link="node" data-node=… [data-nodedb=…]>`；點擊由 `link.ts linkToNode()` 處理＝`anchorVa` 解析 → `linkTo(mode:'node')`（捲動＋行高亮＋目錄游標跟隨）。
- 跨庫：目標庫已開在 slot → `switchTo` 後跳；未開 → 狀態欄提示「請先開啟 X.adb」。查不到 → 「不在庫內」warn。**全部路徑不靜默**（作者 2026-11-13 ybh 回函 §3）。

## 產生器建議

- `<篇>`／`<章>` 都給 `id`：篇＝`W`、章＝`W-V`（全域唯一）。
- 跨著作／跨卷引用一律用**卷級** `W-V#值`；篇級只在全作品唯一時使用。
- 同庫「跳看」用 `<節聯>`（輕）；需要「就地讀原文段」才用 `<嵌>`；大科用 `sub="1"`。

## 多科判樹＝多頁籤（2026-11-13，ybh v5）

一部著作一棵科判樹、一個目錄頁籤（`search.ts:340`「一個 `<樹>` 實例＝一棵樹，多個＝多個頁籤」）。
ybh v5 檔頭並列 17 棵 `<樹>`：主樹 `t="篇,章,科01,…,科54."`（T1579 本論）＋ 每部釋論一棵純科判樹
`t="科漢01,…,科漢54."`（披尋記）、`科基`（略纂）、`科釋`（論釋）……各用獨立標籤家族。

- **命名空間仍錨定篇**：主樹的 `t=` 鏈最長（56 層＞各家族樹 ≤54），故 `nodeAnchorIndex` 的
  `nsTag=篇`、`volTag=章` 不變——家族樹不參與命名空間，只提供目錄頁籤。
- **`nodeSubtreeEnd` 的層序**：科判標籤特例化——凡 `^科[一-鿿]?(\d\d)$` 一律 `100+NN`，讓
  「章」（層序 1）恒小于「科X01」（101），子樹界能正確停在卷／更上層，而非誤把同族 index 0 排在 章 之上。
- `<嵌>` 節點分支渲染成**樹形**（`.embedTier` 依 tier 縮排），不把科判平舖（作者：科判也要有樹）。
