# ys.adb 與 yinshun.adb 有什麼不同

`yinshun.adb` 是 1998–2010 年代隨光碟、網站流通的《印順法師佛學著作集》資料庫；
`ys.adb` 是 2026 年用 CBETA 的 Y 部 TEI 重建的「AI 版」。兩本都是同一套著作，
但資料來源、標記與能力都不同。舊版已從公開資料庫下架，新讀者請用 `ys.adb`。

## 一眼看差異

| 項目 | yinshun.adb（舊版，已下架） | ys.adb（2026 AI 版） |
|---|---|---|
| 資料來源 | 自建的 corpus XML | CBETA Y 部 TEI P5（`cbeta-org/xml-p5`） |
| 書 | 44 | 46（44 冊＋後記＋附錄） |
| 卷 | 沒有 `<卷>` | 462 |
| 章／節／項 | 510／1,570／1,091（混用科判標籤） | 1,985／1,588／2,632（依 `cb:mulu` 層級） |
| 頁 | 16,994 | 17,516 |
| 頁元 | 63 | 75 |
| 行數 | 266,916 | 329,391（含腳註） |
| 大正鏈結 | 13,918（頁欄級為主） | 29,910（正文 18,466＋腳註 11,444；字元級，另帶大正原文 `q`） |
| 插圖 | 456 張點陣圖（`images/y01-18.png`） | 75 張圖版（64 svg ＋ 11 gif，資源名 `svg/YNN/…`） |
| 字元範圍 `j` | 沒有 | 17,151 個（2026-10-31 重算；長引文整段塗滿） |
| 檔案大小 | 約 24.9 MB | 28.3 MiB |
| 更新方式 | 手動 | 一個腳本從 CBETA 重建（見 `ys-steps.md`） |

## 一、資料來源不同

舊版是作者自己把紙本逐字錄入、再標記而成的 corpus；新版直接吃 **CBETA Y 部 TEI P5**，
所以原書的卷、頁、行、校勘、註記都跟著 CBETA 走。CBETA 修一個錯字，重建一次就同步。

## 二、新版多了什麼

- **後記**：〈2026年AI版後記〉獨立成書，說明這一版的來歷、授權與感謝。
- **附錄**：舊版卷首的五篇（參與人員名單、略傳、略譜、著作出版年表、基金會簡介）
  CBETA 沒有收，新版自動補回，另立「附錄」一書，逐行保存表格。
- **字元級大正鏈結**：29,910 條（正文 18,466、腳註 11,444），每一條都記著大正藏原文，
  所以能反過來在大正藏頁面上顯示「回連結」。其中 17,151 條另帶 `j="起-訖"`，
  點下去只塗那一段（長引文整段塗滿）；沒有 `j` 的仍可用 `q` 比對。
- **印順腳註**：11,125 條，排在引用它的段落後面；滑過〔註〕看注文，
  注文裡的每一筆大正引用各自可點。
- **回連結**：讀大正藏時，被印順引用過的那一行直接出現「般若 114a」這樣的按鈕，
  點一下就在中間開新分頁讀印順；反過來也可以。
- **跳至**：左欄多一個分頁，輸入頁碼、`2p1a7`、`大正2，206a15-b13`、或
  CBETA 的 `(CBETA 2025.R1, T02, no. 99, p. 1a7-9)`，跳到那一段並整段塗色。
- **正確的目錄層級**：部、章、節、項、干、一…依 CBETA 的 `cb:mulu level` 分層（最多 18 層），不再同層並排。
- **註記不再被藏起來**：CBETA 的 `<note>` 一律輸出成獨立的〔註n〕行。
- **圖版**：CBETA 的 `<graphic>` 轉成 `<圖 n="svg/YNN/…" t="圖版"/>`，圖檔取自
  `cbeta-git/CBR2X-figures`（現行版）並補上舊 corpus 的圖，放在
  `D:\2026\xml-p5\Y-images`；SVG 直接內嵌，只有點陣版的（11 張 gif）用 `<img>`。
  例：`8p0052a` 的五趣圖 `svg/Y08/Y08p0052_01.svg`。XML 引用 75 張，全部收得到。

## 三、與舊版不同的地方

- **科判層級**：舊版用 `<甲>`、`<乙>`、`<丙>`…… 這類自製科判標籤分層；新版以 CBETA
  的目次層級為準，科判文字仍在正文裡，但不再自成目錄層。
- **校勘**：`<app>` 只留底本 `<lem>`，異文 `<rdg>` 不進資料庫。
- **頁碼寫法**：`<頁 id="22p0065a">`（冊號＋`p`＋原書頁欄），與舊版不同；
  對外連結一律用大正藏與印順的頁碼，不受影響。
- **`u="文"`**：CBETA 沒有這個屬性，重建時由外部規則檔 `u-attrs.txt` 補上，
  頻次（`*u=文`）不會漏段。

## 四、怎麼重建

```powershell
pwsh D:\2026\ys\build.ps1
```

建置腳本、來源資料（附錄、後記、u= 規則）與完整步驟都在獨立 repo **`D:\2026\ys`**；
第一步要連同本工作區（`D:\2026\adb-converter`）一起，兩個 repo 放在同一個上層資料夾。
**不需要** `yinshun.adb`——附錄與後記都進了版控。
