## 6. 正文與注疏

### 6.1 `<融>`

```text
<融 i="taisho?18p55a" j="0-…"></融>
```

- 建置時從母庫抽正文。
- 只保留正文；`卷／品／分` 由作者源檔另行插入，避免重複樹節點。

### 6.2 `<嵌>`

```text
<嵌 i="taisho?18p24b" j="210-237"
   t="taisho?58p639a@149-176@口傳" n="1 家注疏"/>
```

- `i/j`：經文頁與 Han 範圍。
- `t`：一家或多家注疏目標，`db?page@start-end@label|…`。
- `n`：家數。
- 大日手動加入的 T2214 口傳是 depth 3 的例子：

```text
大日經 T0848
  → 大日經疏 T1796
  → 大日經疏妙印鈔 T2213
  → 大日經疏妙印鈔口傳 T2214
```

### 6.3 目前數量

```text
注疏群索引：1070 群
注疏目標：1584 個
正文成功定位的 <嵌>：1040 筆
```

少數 `<嵌>` 因章節標題把頁面切開、`q` 跨標題而沒有定位；索引仍保留該群。

## 7. `study` block：注疏索引

不用樹展示注疏，改用 adb 內的結構化 block：

```text
taisho-study.adb
└ container: study
   └ block: index   ← UTF-8 JSON
```

讀取：

```ts
const bytes = await reader.readBlock('study', 0);
const data = JSON.parse(new TextDecoder().decode(bytes));
```

內容：

```json
{
  "schema": 1,
  "groups": [
    {
      "book": "金剛般若波羅蜜經",
      "chapter": "法會因由分第一",
```

## 12. 消文型注疏（自動判定）

「消文」指逐句抄錄經文、隨即解釋的作品。判定不看體裁，只看**經文文字覆蓋率**：
把底本經文正規化後切成 8 字窗，通查全藏 3,000 部書；一部書若包含 ≥80% 的經文字窗，
就是該經的消文型作品。

```powershell
bun run build/jingqun/find-xiaowen.ts          # 底本 T235（羅什）
bun run build/jingqun/find-xiaowen.ts 0236a    # 底本 T236a（菩提流支）
```

輸出：

```text
build/jingqun/xiaowen-jingang.tsv    3,000 部逐部覆蓋率（依 cov8 排序）
build/jingqun/xiaowen-jingang.json   摘要 + 消文清單 + 50–80% 鄰近清單
build/jingqun/xiaowen-0236a.*        以菩提流支本為底本的同一份掃描
```

### 12.1 三個指標

| 欄 | 意思 |
|---|---|
| `cov8` | 經文 8 字窗出現在書中的比率＝**文字覆蓋率**（主判定） |
| `sentenceCov` | 以 `。！？；` 切出的 316 句，整句原樣出現的比率 |
| `ordered` | 兩邊 8 字窗序列的最長公共子序列比率（順序覆蓋）；句下釋因夾註切斷窗，只作參考 |

判定採 `cov8 ≥ 80%`（母經 T0235 本身是 100%，不列入）。`sentenceCov` 只作參考：
卍續藏多數消文的句覆蓋只有 63–87%，因為夾註、科判會把整句切斷。

### 12.2 羅什本 T235 的消文：4 部

|---|---|---|---:|---:|---:|---:|
| T2732 | 梁朝傅大士頌金剛經 | — | 85／古逸部 | 98.9% | 89.6% | 89.5% |

### 12.3 其他譯本的消文：不能算在 T235 頭上

以下三部以 T235 量只有 76–78%，但改以 T236a（菩提流支譯）為底本即達 97–98%；
它們是**菩提流支本的消文**，不是羅什本的消文：

| 大正號 | 書名 | 對 T235 | 對 T236a |
|---|---|---:|---:|
| T1704 | 金剛般若波羅蜜經略疏（唐 智儼述） | 76.4% | 98.0% |
| T1511 | 金剛般若波羅蜜經論（天親造） | 78.0% | 97.9% |
| T1510b | 金剛般若波羅蜜經論（無著造） | 77.5% | 97.6% |

判別竅門：這些書開頭引的是「一時婆伽婆在舍婆提城…」，羅什本是「一時，佛在舍衛國…」。
study 現有的「天親論／無著論」目標因此是**義**的對應，不是同一譯本的文字對應。

### 12.4 未達門檻的殘本

古逸部敦煌本多為殘卷，闕字（□）與脫漏使覆蓋率不足：

| 大正號 | 書名 | cov8 | 句覆蓋 |
|---|---|---:|---:|
| T2739 | 金剛般若經挾註 | 77.9% | 60.0% |
| T2737 | 金剛經疏 | 71.2% | 41.1% |
| T2736 | 金剛般若經依天親菩薩論贊略釋秦本義記卷上 | 53.2% | 36.0% |

### 12.5 論疏部不是重點

原以為消文在論疏部，實測不然：論疏部 35 部中對 T235 覆蓋最高的是
T1816《金剛般若論會釋》10.2%——它消的是《金剛般若論》，不是經文。
真正逐句消文的作品都在**經疏部**與**古逸部**。

### 12.6 對 study 的意義

- 要補「逐句消文」的注疏群，優先加 T1700、T2732。
- 既有 T1511／T1510b 目標宜標明「依菩提流支本」，避免與 T235 字面對齊時誤判。
- 同一方法可換底本（T236a、T262 法華、T848 大日）重跑。
