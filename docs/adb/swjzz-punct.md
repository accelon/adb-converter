# swjzzp：把「中华典藏网」的標點借進 `swjz.xml`

> 目的：`swjz.xml` 本身只有稀疏的句讀（「。」「、」），沒有書名號。網路上有一份
> **簡體＋現代標點**的《說文解字注》（中华典藏网，136 段），把它斷句用的標點（含《》）
> 按字對回繁體原文，就得到一份「有書名號標點」的文本。

## 1. 來源與授權

* 文字：`https://www.diancangwang.cn/xueshuzaji/b425b900dc24/`（中华典藏网《说文解字注》，136 段）
  —— 簡體、現代標點、每字一條「注解：…」。
* 站方是「非营利性站点…仅供学习」，抓取時每頁間隔 300ms、只抓一次（136 頁）；
  這份資料**只用來借標點**，不進任何交付物，交付的 `.adb`／`.xml` 仍是原本的繁體正文。

## 2. 做法（`ts/tools/swjz-punct.ts`）

1. **抓**：`fetch-dcw.ts` 把 136 段抓下來存 `dcw/pNNN.txt`（去掉站方的隱藏水印 `<span>`）。
2. **拆條目**：每條 = 一個「注解：」段落 ＋ 往前找最近的一行短漢字（網站有時把字頭寫成
   `标题：X`，有時中間夾著拼音行或「路径：」行）。
3. **配對**：兩邊都在文件順序，先比字頭（都轉簡體比），字頭對不上再比「開頭四個字」——
   網站有 □（缺字）、異體（祐／佑、祕／秘），本站又多了重文與 540 個部目。
   配對成功 7,323 條（網站 9,392 條、本站 11,246 個字頭）。
4. **對齊**：每一條網站文字要對上「從這一條到下一條之間」的**所有**本站字頭
   （網站把「弌」「𢂇」這種重文併在母字那一條裡）。兩邊都只比**內容字**（本站原有的
   「。」「、」先排除），用雙指標＋前後找重同步的方式對齊 → 字元對上 **95.2%**。
5. **貼標點**：網站每個字前面有哪些標點，就貼到對應的本站字前面；本站同一位置已經有標點的
   話，同一個文字節點內直接換掉（例「曰。」→「曰：」），跨 `<說文>`／`<段注>` 標籤的就只補
   多出來的那一半（例「。」＋「。《」→ 只補「《」），避免把標籤吃掉或重複。
6. 交付：`swjz-punct.xml` → `swjz2adb.ts --ref` → `swjz-pack.ts … swjzzp`。

## 4. 已知限制

* **只借標點，不借字**：字仍然是 `swjz.xml` 的繁體原文；網站是簡體，兩邊用 Unihan 的
  繁→簡對照比對，遇到一簡對多繁（發／髮、乾／幹…）或異體時可能對歪，這正是那 174 條
  <80% 的來源。
* **跨片段**：本站把說文與段注分成不同標籤，網站是連續一段；標點落在片段交界時，
  開引號／書名號會留在前一段的尾或後一段的頭（兩種都不算錯，但排版上會看到）。
* **網站本身有錯字與漏字**（□ 缺字很多），所以標點偶爾會貼在錯的位置；
  要更準就得人工校對那 174 條（清單可由 `swjz-punct.ts` 的 `worst` 輸出）。
* 目前的 `swjzz.adb`（無標點）**沒有被覆蓋**；`swjzzp.adb` 是另一顆庫。
  要讓 `swjzz` 也帶標點，把 `swjz-punct.xml` 丟給 `swjz2adb.ts` 再打包成 `swjzz.adb` 即可
  （指令同 §2.6，只改輸出名）。
