# 表格：`<表>` 與框線字藝術

> 作者 2026-11-06 定案：**只加一個標籤 `<表>`**，其餘用「一列一行、`|` 分格、
> `|---|` 表頭線」的規則解決。既有的框線字藝術（`<圖文字>`）自動認得出來就轉成
> 同一種表格，認不出來就原樣用等寬顯示。

## 1. 為什麼需要一個標籤，而不是像 Markdown 那樣自動認

實測 108 個 adb：語料裡**沒有真正的 Markdown 表格**，但 `|` 到處都是——

| 庫 | 實際狀況 |
|---|---|
| yinshun | 113 行用 `\|`／`+---`／`┌──┐` 畫的**圖解**（生滅緣起圖），長得和表格一模一樣 |
| thonzu | 490 行含 2 個以上 `\|`，是電子報報頭（` \| 期號 \| 日期 \| …`）的單行橫幅 |
| taixu | `<表>圖說</表>` ＋ `<圖/>` ＋ `<圖文字>` 裡 5 欄的框線表 |
| thonzu | `<表>` 包多行（圖＋文字），是區塊容器 |

所以「看到管線就當表格」一定會誤傷（yinshun 的圖解會變成 1 欄殘表）。
**邊界由 `<表>` 決定**，內容才由規則解析。

## 2. 語法（新內容一律這樣寫）

```text
<表>
表1　三種譯法的比較
項目 | 梵語 | 次數
:--- | :---: | ---:
涅槃 | nirvāṇa | 12
不生 | anutpāda | 31
</表>
```

| 規則 | 說明 |
|---|---|
| 一列一行 | 硬規則。位置（`L{n}` 錨點）、引用、分頁都以行為單位，一列不能跨行 |
| 分格 | 只有 **ASCII `\|`** 分格；全形 `｜` 永遠是文字（中文稿常用，不必跳脫） |
| 表說明 | 區塊裡**第一行不含 `\|` 的文字**＝說明（`<caption>`）；寫在 `<表>說明</表>` 同一行也可以 |
| 表頭 | 有對齊列（`---`、`:---:`、`---:`）時，**前一列是表頭**；沒有就全部算表身 |
| 對齊 | 由對齊列的 `:` 決定（`l`／`c`／`r`） |
| 跳脫 | cell 內要字面的 `\|` 寫 `\|`；`<標籤 …>` 內與 `&…;` 內不切格 |
| 欄數 | 以第一列為準，**不一致就整張拒絕**（寧可不出表，也不要錯位） |
| 空白格 | 留空（作者 2026-11-06）。空白是資料，不要放「…」之類的符號 |
| 一格只能放行內標籤 | `<術>`／`<註>`／`<聯>` 都可以；段落、清單、巢狀表格不行 |
| 頁碼 | 表格中間的 `<頁 id="…"/>` 會變成整列合併的「原書頁 xxx」列，位置不動 |

**不能表達的**（要就用圖，或拆成兩張表）：`colspan`／`rowspan`、一格多段、
巢狀表格、格內插圖。

## 3. 框線字藝術（既有資料，自動轉）

`<表>` 與 `<圖文字>` 兩個區塊的內文都會先試著解析：

1. 先試管線表（第 2 節）。
2. 再試框線表：`┌─┬─┐` 頂框、`│ … │ … │` 內容列、`├─┼─┤` 表頭線、`└─┴─┘` 底框。
3. 都不成立：
   * `<圖文字>` → 整段用**等寬**顯示（`.figText`，橫向捲動）——框線圖至少對得齊；
   * `<表>` → 照舊當普通文字（單行的 `<表>說明</表>` 當圖說，置中、小一號）。

**接受條件**（缺一不可，見 `parseBoxTable`）：頂框與底框接點數相符、每列 `│` 的
個數一致、至少 2 欄 2 列、列以外的行只能是純頁碼。框線**寬度對不齊沒關係**
（OCR 過的藝術表，框線常常只有內容的一半寬），因為只認 `│` 的個數，不看字元位置。

**已知限制**：藝術表的「列」是視覺列，不是邏輯列。原圖裡換行的同一個儲存格
（例：taixu「日本朝鮮二國／國文屬之」）會被拆成兩列；空白格留空。
要合併得靠人工或 AI 判斷，不能靠空白推。

## 4. 實作

| 檔案 | 做什麼 |
|---|---|
| [../ts/src/accelon26/table-block.ts](../../ts/src/accelon26/table-block.ts) | 兩種寫法的解析器（純函式，不碰 DOM） |
| [../ts/src/accelon26/render_accelon3.ts](../../ts/src/accelon26/render_accelon3.ts) | `blockRegionAt`／`blockAt`：把區塊收成 `RenderBlock{kind:'table'\|'pre'}`；`tableHtml()` 產生 DOM |
| [../ts/src/accelon26/doc-pane.ts](../../ts/src/accelon26/doc-pane.ts) | `renderBlocks` 的 table／pre 分支；`pageEndAtBlock` 讓表格不跨頁 |
| [../ts/src/accelon26/paint.ts](../../ts/src/accelon26/paint.ts) | 塗紅逐格找（`querySelectorAll('.lineText')`） |
| [../ts/test/table-block.test.ts](../../ts/test/table-block.test.ts) | 30 項單元測試（含 taixu 真實資料與 yinshun 圖解的拒絕） |

**塗紅的契約**：每列仍是 `.docLine`（`id=L{n}`、`data-src=整行原文`），每格是
`.lineText`，所以「VA → 取那幾個字 → 在 `.lineText` 裡找字」這條路不變。
用 `<table>`／`<tr>`／`<td>` 只是讓欄寬交給瀏覽器；`display` 由
`.docTable tr.docLine { display: table-row }` 交還給 table layout。

**分頁**：頁尾若落在 `<表>`／`<圖文字>` 中間，`pageEndAtBlock` 往下補到收標籤
（最多 80 行），表格整塊留在同一頁。

**表格前的純圖列**（`<圖/>` 只有一張圖、沒有文字）：緊接在表格前面時會被**收進表格下面的
「看原圖」**（`hoistImagesBeforeTables`＋`.tblSrc` 的 `<details>`）——文字表優先顯示，
要校對 OCR 時再展開掃描原圖。找不到圖檔（只有 `▢`）就整列丟掉，不留一個沒用的按鈕。

`<圖>` 的檔名可以寫 `n=`、`id=` 或 `f=`（`f` 是 Delphi 的 FILE 屬性；taixu 的表格掃描
就是用 `<圖 f="images/09-0134.png"/>`，資源在 `resources` 裡）。

## 5. docx → `<表>`

`ts/tools/docx-tables.py`：讀 `.docx` 的 `w:tbl`，輸出 `<表>` 區塊（管線列），
處理 `gridSpan`（橫向合併→補空格）與 `vMerge`（縱向合併→續列留空）。
只印出「`<表>` 能表達」的表（沒有合併到無法表達、沒有巢狀表、沒有圖片）；
其餘列進 `--report` 讓作者決定要不要繼續用圖。

福嚴（`D:\2026\fuyan`）的管線目前把表格交給 `--figures` 變 SVG；要改成文字表，
把 `docx2accelon.py` 的 `table_lines()` 換成這裡的 `emit_table()`，並讓
`--figures` 跳過 `k == 'tbl'` 的 block（詳見該工作區的 `docs/PIPELINE.md`）。
