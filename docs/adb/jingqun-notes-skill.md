# 金剛經注疏讀本：另一個小 adb（`<融>`／`<嵌>`）

> 目的：把「經文＋注疏」做成一個 **0.06 MiB 的小庫**，不要讓讀者為了看注疏
> 重新下載 300 MiB 的 `taisho.adb`；讀者也可以用自己的注疏源檔，鏈回原文。
> 本讀本**依賴 `taisho.adb`**：經文與註疏都從大正藏取，小庫只存讀本與指針。

## 1. 為什麼另立一庫

| 庫 | 大小 | 內容 |
|---|---:|---|
| `taisho-85.adb` | 311 MiB | 大正藏 1–85 冊全文（母庫） |
| `jingang.adb`（本讀本） | 0.06 MiB | T235 經文（13 頁）＋ `<嵌>` 指針；註疏取自母庫 |

本讀本不改 `taisho.adb`；要更新經文或注疏，只重建這個小庫。
讀者同時開著 `taisho.adb`，`<嵌>` 的 `t="taisho?…"` 才有頁可讀。

## 2. 作者源檔：`jingqun/jingang.txt`

源檔只有三種東西：精簡 `<檔>`、`<融>`、`<嵌>`／說明文字。

```text
<檔 n="jingang.xml">
<集 c="hidden">金剛經注疏讀本</集>
<樹 s="*" t="書">金剛經</樹>
<樹 s="$書" pf="$頁.id;)" sf="-$書.id;">書名</樹>
<樹 s="*詞">全文</樹>
<隱><引>《$書;》：「$_;」( $*頁; )</引><摘要頭>$書;($頁;)</摘要頭></隱>
</檔>
<段/><書 id="n1">金剛經注疏讀本</書>
<卷>金剛般若波羅蜜經</卷>
金剛經注疏讀本
本讀本以《金剛般若波羅蜜經》正文為底本；
段落後標出大正藏註疏家數，點開可就地讀各家解釋。

<融 i="taisho?8p748c" j="0-181"></融>
<嵌 i="taisho?8p748c" j="19-90"/>

<融 i="taisho?8p749a" j="0-430"></融>
<嵌 i="taisho?8p749a" j="73-145"/>
…
```

**目錄不再有大正藏的冊／部**：沒有 `<冊 id="8">般若部四</冊>`，也沒有「經疏部一」那層。
`<樹 s="*" t="書">金剛經</樹>` 讓「金剛經」成為第一層，下面只有
「金剛經注疏讀本」一本；六部註疏不再放進本庫，`<嵌>` 直接指到 `taisho.adb`。

### `<融>`：把經文融入本文

源檔是**空殼**，指針留在 `i`／`j`：

```text
<融 i="taisho?8p748c" j="0-181"></融>
```

- 概念等於 Obsidian 的 `![[大正藏#8p748c]]`。
- `i`：母庫 `taisho` 的頁；`j`：該頁的漢字範圍（`0-181` 表示整頁 181 個漢字）。
- 建置時，若 `<融>` 裡面是空的，就從母庫抽該頁，寫成
  `<融 i="…" j="…">完整經文</融>`。
- 這個 `<融>` **會留在 adb 裡**，包住的文字是真正的正文，所以會被 token/index 檢索到。
- 讀者看到的是一般正文，沒有晶片、沒有跳頁、沒有「引用框」。
- 用戶可以自由編輯 `<融>` 包住的文字；建置時只要裡面**非空**就保留，
  不會覆蓋。若把文字丟掉（留空殼），下次建置會再從母 adb 抽回來。
- 因此：**有母 adb 時，`<融>` 包住的文本是可以丟掉的**；指針才是身份。

### `<嵌>`：段落後的注疏群

```text
<嵌 i="taisho?8p749a" j="73-145"/>
```

- `i`：頁；`j`：**頁內漢字範圍**；和 `<融>`、`<聯>` 完全同一套。
- 建置時以 `i`＋`j` 到 `jingang-groups.tsv` 查 `q`、目標清單與家數
  （group 的 key 是 `page:relStart-relEnd`）。
- 建置時在段落起點插 `<嵌始 i="…" j="…"/>`，在段尾插
  `<嵌 i="…" j="…" t="taisho?…" n="5 家注疏"/>`。
- 不再有 `e`（群組 id）、`p`（頁）、`l`（行）：那三個是舊的自訂欄位，
  和 `<聯>` 不一致，已移除。
- **源檔不必寫 `q`、`t`、`n`**；這些由 groups.tsv 補，`t` 的庫名改成 `taisho`。
- `q` 仍可選：手寫註疏不屬於既有 groups 時，可寫 `q`（或 `i`／`j`）當定位器。
- **`q` 不會進入 adb**；執行期只需要 `i`／`j`／`t`／`n`。
- 讀者點晶片時：正文亮起，下方只列各家解釋，不重複經文。
- 目標頁在母庫 `taisho`，所以讀者要同時開著 `taisho.adb`。

## 3. 建置流程

```powershell
# 1) 由 groups.tsv 產生作者源檔 jingqun/jingang.txt
bun run jingqun/notes.ts

# 2) 空殼 <融> 從母 adb 填文；非空的保留；定位 <嵌>
bun run jingqun/build-notes.ts
#    → build/jingqun/jingang-notes.txt（<融> 內有可檢索的正文）

# 3) 打包成小庫
bun run ts/tools/tei-pack.ts build/jingqun/jingang-notes.txt build/jingang.adb `
  jingang 金剛經經論群 "" ""

# 4) 驗證
cd ts
bun run test:notes
```

目前產出：

```text
pages=13  annotations=92  placed=92
wrote jingang.adb: 0.06 MiB, 471 lines, 28 tags（正文 10.5 KB；其餘是 logo）
ok: 39 chips; first = 本段經文共有 3 家注疏 …
```

驗證時要同時開母庫：

```powershell
bun run tools/embed-test.ts --adb ../build/jingang.adb `
  --dep build/taisho-85.adb --dep-wait 30000
```

## 4. 讀者自己做注疏

1. 複製 `jingqun/jingang.txt`，改成自己的讀本。
2. 用 `<融 i="taisho?頁id" j="0-N"></融>` 融入想讀的經文頁。
3. 用 `<嵌 i="taisho?頁id" j="起-訖"/>` 加注；若群組不在 `groups.tsv`，
   再補 `t="taisho?頁@範圍@名稱"`，必要時用 `q` 定位。
4. 跑 `build-notes.ts` + `tei-pack`，得到自己的 `.adb`；閱讀時同時開 `taisho.adb`。

`t` 的目標頁在母庫 `taisho`；本讀本不再複製六部註疏。

## 4.1 從大正藏選取 → 貼進研究庫

同時開著 `taisho.adb` 與 `jingang.adb`，在 `taisho.adb` 選一段文字，
放開後選單會多兩項：

| 選單 | 產生的片段 | 用途 |
|---|---|---|
| **融入引用** | `<融 i="taisho?8p749a" j="56-61"></融>` | 把這段文字直接融入讀本正文 |
| **嵌入引用** | `<嵌 i="taisho?8p749a" j="56-61" q="選取文字" t="taisho?8p749a@56-61@…" n="1 家注疏"/>` | 把這段文字掛到某個經文段落後 |

- 兩個片段都會複製到剪貼簿，狀態列會提示「貼到 jingang.txt」。
- `j` 是頁內漢字範圍，由 `pageHanText()` 對選取文字定位。
- **融入**：直接貼在 `jingang.txt` 想要的位置；建置時會從 `taisho` 抽這段填入 `<融>`。
- **嵌入**：貼在要標記的經文段落後。若選的是注疏文字，`q` 要改成該段經文
  （或改用 `i`／`j` 指針），因為 `q` 是讀本裡的定位錨。
- 存檔後跑 `notes.ts`／`build-notes.ts`／`tei-pack`，就得到自己的研究庫。
- `jingang` 是**終點庫**：選取選單不顯示「引用複製」；在 `taisho` 等其他庫仍保留。

目前選單只做「產生並複製片段」，貼上與修改仍在 `jingang.txt` 進行；
下一步可做剪貼簿直接插入編輯器。

## 5. 目前限制

- **讀本依賴母庫 `taisho.adb`**：`<嵌>` 的目標頁在母庫；閱讀時要同時開著。
  好處是小庫只有 0.06 MiB，不必複製六部註疏。
- 點 `大正↗` 時會用目標的 `j` 範圍先抽 `quote`，右欄開啟後直接塗紅那一段，
  不需要使用者再捲動尋找。
- **`<融>` 是建置時填文**，不是執行期向 `taisho.adb` 取文；填進來的正文仍可被索引。
- `q` 比對忽略空白，但**標點要一致**；版本異體字（説／說）目前不折疊。
- 目前由 `notes.ts` 自動產生 92 個 `<嵌 i="…" j="…"/>`；`q`／`t` 由 groups.tsv 補。
  讀者手寫的 `<嵌>` 若不在 groups，需自行給 `t`，必要時給 `q` 或 `i`／`j`。
- `Ctrl+大正↗` 的目標是母庫，所以在本讀本裡開的是**右欄新分頁**，不是本側。
