# 引用對應表（cite map）：讓「講義 ↔ 原書」的連結不必每次重掃原書

作者 2026-11-01。給 **builder**（任何把 docx 講義轉成 adb 的流程）複用的通用設計。
第一份實作在 `fuyan`（釋厚觀《空之探究講義》→ ys.adb），已完成並驗證。

## 1. 問題

講義引用原書的寫法是「《書名》，第X章，第Y節〈標題〉，p.NN」，有時再加「，注N」。
若每次重建都拿這些引文去掃原書（ys.adb 25 MB、7 萬頁），一次要幾十秒到幾分鐘；
而講義 docx 每次只改幾個字，重掃整本原書並不划算。

## 2. 關鍵觀察（穩定性假設）

| 東西 | 會不會變 | 說明 |
|---|---|---|
| 引文文字（書名＋章節＋標題） | **幾乎不變** | 講義是從原書複製貼上，作者只會在句子前後增減 |
| 頁碼 `p.NN`、`pp.NN-MM` | 會變 | 只能當提示，不進 key |
| 注號 `，注N` | 會變（重編） | 不進 key |
| 原書的頁 id／字元位置 | 會變（原書重建） | 用文字重新定位，不用座標 |

→ **以「正規化引文」為 key，值是「原書頁 id ＋ 漢字範圍 j」**。

## 3. 資料結構

`data/<book>-cites-map.tsv`（Tab 分隔）：

```
# 引用 → 原書頁
《空之探究》，第一章，第三節〈空與心解脫〉	38p0020a
《空之探究》，第三章，第八節〈空與一切法〉	38p0225a
《原始佛教聖典之集成》，第十二章，第一節〈九分教與十二分教〉，pp.493-627	35p0493a
```

- **key**：`《書》，第X章[，第Y節][，第Z項][〈標題〉]`，比對前去掉標籤與空白。
  章之後允許「節／項／目」與「〈標題〉」任意交錯（講義的寫法不統一）。
- **頁 id**：目標資料庫的頁。
- **j**（可選）：目標頁內的漢字範圍；有引文比對時才有。

## 4. 流程（`src/cites.py`）

```bash
python src/cites.py extract   # 掃原書、補連結、順便把新 key 寫回表（慢，偶爾做）
python src/cites.py apply     # 只查表（快，每次 docx 重建後做）
python src/cites.py rebuild   # 由已標好的文字重建表（原書重建後重掃一次）
python src/cites.py verify    # 壞連結檢查（目標頁不存在 = 0 才可打包）
```

- **extract**：只在第一次或原書重建時做；新的引用會自動進表。
- **apply**：每次重建都做，不碰原書，只查表。
- **verify**：所有 `<聯>` 的目標頁必須存在；不存在就拆掉（不能讓點擊落空）。

## 5. 實測（2026-11-01，yl38 → ys）

| 指標 | 數值 |
|---|---|
| 講義裡的引用行 | 420（其中 2 行不是印順著作或跨行斷開） |
| 已建立連結 | 418 行（1,441 條 `<聯>`） |
| 目標頁不存在的連結 | **0** |
| 對應表筆數 | 150 |
| `apply` 重跑（不掃 ys） | 199 筆套用、結果與 extract 完全相同 |

⇒ 換版本時只需 `apply`，毫秒級；只有「新出現的引用」才需要 `extract`。

## 6. 擴充

- 多本書可共用一張表（key 以書名開頭），或每本書一份。
- 原書重建後：`rebuild` 一次即可（用已標好的文字反推），不必逐筆掃。

## 6.1 未定案：「p.NN，注M」連到注文（2026-11-01 試過三輪，暫停）

**目標**：講義寫「《空之探究》，第一章，第三節〈空與心解脫〉，p.23，注4」時，
希望點一下就到 ys 的「注 4」那條釋文，而不只是那一頁。

**為什麼做不到**（三個獨立的阻礙，都已實測）：

| 障礙 | 實測結果 |
|---|---|
| `ys.adb` 沒有原書注號 | 註是全域流水號（`38.060`、`38.061`…），與原書「注4」無對應欄位 |
| `yinshun.adb` 也沒有 | 註號是 `1.001`、`2.001`、`3.004`… 「書號.流水號」，同樣是重編的 |
| CBETA Y XML 也沒有 | `<note n="0001001" cb:note_key="Y01.0001a01.11">` 是 CBETA 自己的編號 |

試過的補救與結果：

1. **同頁第 M 個 `<註>`**：47 筆只中 4 筆（多數頁的註數少於 M）。
2. **同節第 M 個 `<註>`**：0 筆——《空之探究》在 ys 裡沒有 `<節>` 標記，無法界定節範圍。
3. **用「注N：」後面的文字掃全書**：15/47 命中，且抽樣發現誤中索引頁
   （`38pz009a/b` 是《空之探究》的索引頁，短句密集，最容易被撞到）。
   排除索引頁後降到 0 —— 因為講義的「注N：」後面多半是自己的轉述或
   「參見某某書」，不是原書注文原句。

**目前做法**：`<聯>` 只連到引用頁（`ys?38p0023a`），「注4」留在文字裡當說明。
連結不落空、也不會誤導。

**若日後要做，前提是**：拿到「原書注號 → 注文」的對照來源（掃描書 OCR、
作者整理的注號表、或某個保留原書注號的版本），把那份對照放進
`data/<book>-notes-map.tsv`（`注號 \t 目標頁 \t j`），再接進來即可；
屆時 `cites.py` 只要多一個 `--notes-map` 參數。
