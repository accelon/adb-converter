# 大正藏「經／論／律 → 注 → 疏」繼承表

> 把 `taisho.adb` 的 3,000 部書按「所釋的本經／本論」串成三層繼承：
> **經／論**（root）→ **注**（直接釋經或釋論）→ **疏**（釋注，可再往下）。
>
> 第三版：**379 部註疏、479 個節點、81 個群（含論群、律群）**。
> 覆蓋釋經論部、經疏部、續經疏部、論疏部、續論疏部、律疏部、續律疏部，以及諸宗部／古逸部中
> 可判定的註疏。成品在 [`jingqun/jingqun.tsv`](../../jingqun/jingqun.tsv)，
> 可離線看的樹在 `build/jingqun/jingqun.html`。

## 1. 為什麼要做

大正藏的目錄只告訴你「這是經疏部／論疏部」，不告訴你《金剛般若經疏》釋的是哪一部經、
《俱舍論頌疏抄》釋的是哪一部疏。但讀者要的是：

```text
金剛般若波羅蜜經（T235）
├─ 金剛般若論（T1510a，無著造）          ← 注
│   └─ 金剛般若論會釋（T1816，窺基）      ← 疏
├─ 金剛般若經疏（T1698，智顗）            ← 注
├─ 金剛般若經疏論纂要（T1701，宗密）      ← 注
│   └─ 金剛經纂要刊定記（T1702，子璿）    ← 疏
└─ …
```

論群也一樣：

```text
阿毘達磨俱舍論（T1558）
├─ 俱舍論記（T1821，普光）                ← 注
├─ 俱舍論疏（T1822，法寶）                ← 注
└─ 俱舍論頌疏（T1823，圓暉）              ← 注
    ├─ 俱舍論頌疏正文（T2253）             ← 疏
    └─ 俱舍論頌疏抄（T2254）               ← 疏
```

有了這層關係，才能做「同一部經／論的所有註疏」清單、經群導覽、以及
「這句話在哪些註疏裡被解釋」的跨書檢索。

## 3. 證據從哪來

### 3.1 最硬：CBETA 的 `[cf. No. N]`

CBETA TEI 正文第一行常是：

```text
No. 1698 [cf. No. 235]
```

意思是「T1698 這部疏，對應 T235 這部經」。這行也原樣進了 `taisho.adb`
（在 `<頁>` 之後、正文之前），所以不是外部猜測，而是資料本身带的交叉引用。

第三版 379 部中有 **179 部**自帶 cf；其餘 **200 部**用人工種子。

cf 也會指到另一部註疏，這時它是「parent」而不是「root」，要再往上繼承：

```text
No. 1833 [cf. No. 1830]  →  T1833 演祕 釋 T1830 述記，root 是 T1585 成唯識論
No. 2784 [cf. No. 1535]  →  T2784 釋抄 釋 T1535 大乘四法經釋，root 是 T772
No. 1805 [cf. Nos. 1428, 1804] → T1805 資持記 釋 T1804 行事鈔，root 是 T1428 四分律
No. 2284（無 cf，人工）   →  T2284 指事 釋 T1668 釋摩訶衍論，root 是 T1666 起信論
```

build.ts 用一張 `CF_PARENT` 表處理這種「cf 指到註疏」的情況，其餘 cf 直接當 root。

### 3.2 人工種子

續經疏部、續論疏部幾乎沒有 cf；論疏部也有幾部沒有。這些依題名、部類次序、
以及「疏的疏」再分層指定。例如：

```text
成唯識論（T1585）
├─ 成唯識論述記（T1830）                  ← 注
│   ├─ 成唯識論演祕（T1833，cf 1830）      ← 疏
│   ├─ 成唯識論述記序釋（T2260）           ← 疏
│   └─ 成唯識論述記集成編（T2266）         ← 疏
├─ 成唯識論了義燈（T1832）                ← 注
│   └─ 唯識義燈増明記（T2261）             ← 疏
└─ 成唯識論本文抄（T2262）／同學鈔（T2263）／聞書（T2264）…
```

## 5. 四個點名的經

├─ 述義（T2202）、祕鍵開門訣（T2204）

**解深密經**：T675《深密解脫經》與 T676《解深密經》是同本異譯，但**大正藏沒有註疏**；

## 9. 資料怎麼用

### 9.1 TSV

`jingqun/jingqun.tsv` 一列一個節點。`idx` 直接對應 adb 的 `<書 id="n{idx}">`：

```text
family  class  depth  idx   no      title                  parent_no  root_no
f_jushe   注   1    1892  1821    俱舍論記                1558       1558
f_jushe   疏   2    2329  2249    俱舍論本義抄            1558       1558
f_jushe   疏   2    2333  2253    俱舍論頌疏正文          1823       1558
```

要跳到書，用 `idx`（例：`n1821`）；要比對經號，用 `no`。

### 9.2 JSON

`build/jingqun/jingqun.json` 是同一棵樹的巢狀版：

```json
{
  "no": "1558", "idx": 1625, "title": "阿毘達磨俱舍論",
  "cls": "論", "depth": 0, "evidence": "root",
  "children": [
    { "no": "1821", "idx": 1892, "title": "俱舍論記",
      "cls": "注", "depth": 1, "evidence": "cf:No.1558", "children": [] },
    { "no": "1823", "idx": 1894, "title": "俱舍論頌疏",
      "cls": "注", "depth": 1,
      "children": [
        { "no": "2253", "idx": 2333, "title": "俱舍論頌疏正文",
          "cls": "疏", "depth": 2, "children": [] }
      ] }
  ]
}
```

`family` 讓同一部經／論的不同譯本（T235／T236／T239、T1666／T1667）併成一群；
`root` 才是實際懸掛註疏的那個譯本。

## 10. 限制與待辦

1. **56–84 冊的 `<書>` 題名原本是空的**。`cmd/tei2adb` 只認
   `<title level="m">`，而這 541 部用「大正新脩大藏經數位版, No. N 題名」。
   Go 已補 fallback，`build/taisho-85.adb` 已於 2026-10-28 重建，
   3,000 部書名全部非空（`cachedStrings('書')` 驗證）。
2. **未納入**：續諸宗部（70–83 冊，多為宗派著作）、若干古逸部疑偽經與儀文。
   律疏只納入《四分律》《梵網經》兩個根；五分律、僧祇律、十誦律、
   根本說一切有部律在大正藏沒有對應的疏。
3. **多經或會部**：十住毘婆沙論（T1521）、彌勒菩薩所問經論（T1525）、
   寶髻經四法憂波提舍（T1526）、三彌勒經疏（T1774）、淨土三部經音義集（T2207）
   以主要本經掛樹，`note` 有說明；若要做精確的多父節點，需改成 DAG。
   其中兩部按原文修正：T1521 釋 **T286 十住經**（十地品舊譯，不是 T287 十地經）；
   T1526 釋 **T397 大集經**寶髻菩薩品（論序明說「大集中之一集」，不是大寶積經）。
4. **異譯**目前只是同一 family 的兄弟 root，沒有再細分「同本」的版本關係。
5. **低信心 4 部**：T2231 蓮華胎藏界儀軌解釋（釋儀軌而非經）、
   T2232 梵嚩日羅駄覩私記（題名未能確指所釋）、T2281 明本抄、T2282 明要抄
   （因明類，暫掛 T1630）。另有 12 部 medium（含 T2788／T2789 律戒本疏）。
6. **廣百論**：T1571《大乘廣百論釋論》本身是 T1570《廣百論本》的釋論，
   本表暫把 T1571 當論根，T2800 掛其下；若要三層，可再拆 T1570 → T1571 → T2800。
7. **律群只有兩個根**：四分律（T1428／T1429／T1430）與梵網經（T1484）。
   僧羯磨（T1809）、尼羯磨（T1810）等行儀掛在四分律下，class 為「注」，
   但它們不是嚴格意義的「疏」。

## 11. 檔案與重跑

| 檔案 | 說明 |
|---|---|
| `jingqun/jingqun.tsv` | 成品（479 列） |
| `jingqun/catalog.ts` | TEI 檔頭 + `taisho.tsv` → 3,000 筆書目 |
| `jingqun/cf.ts` | 抽每一個作品的 `[cf. No. N]` |
| `jingqun/build.ts` | 書目 + cf + 人工種子 → TSV／JSON |
| `jingqun/render.ts` | JSON → HTML 樹 |
| `jingqun/summary.ts` | 族群統計表 |
| `jingqun/check.ts` | 驗證 parent／root／depth／cf／覆蓋 |
| `build/jingqun/jingqun.json` | 巢狀樹（給應用用） |
| `build/jingqun/jingqun.html` | 可離線看的樹 |

```powershell
bun run jingqun/catalog.ts   # 3,000 個 TEI 檔頭
bun run jingqun/cf.ts        # 3,000 個檔的 cf 掃描
bun run jingqun/build.ts     # 繼承表
bun run jingqun/render.ts    # HTML
bun run jingqun/check.ts     # 驗證
```

來源可用 `TAISHO_TEI`、`TAISHO_CATALOG` 覆寫。
