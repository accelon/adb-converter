# ADB 版本紀錄（canonical）

> 2026-11-01 建立。**每一個 adb 工作區建置／發布後，都在這一頁加一列。**
> 原因：adb 穩定之後，原工作區可能不再使用；這一頁是之後「簡單維護」時的
> 版本真相。`deploy/adb-history.json` 是 manifest 自動產生的機器版，這一頁是
> 人看的紀錄（含「哪個工作區做的、為什麼」）。

## 規則

1. 一次建置＝一列；**不要改舊列**（只有更正錯字可以）。
2. 欄位：日期（北京）、adb、sha256（前 12 碼即可，完整值在
   `deploy/adb-notes.json`）、大小、buildTime（UTC）、工作區、說明。
3. 說明寫「這次改了什麼、影響哪個座標」，不要只寫「更新」。
4. 發布（上傳兩站）與否要註明；官網只在使用者說「發佈」時才上傳。
5. 底座的 `cbeta-base.json` 是另一本帳（CBETA 換版用），不要混。

## 之後怎麼做（給 adb 工作區）

1. 建置完成、`pack` 之後，把新 sha／size 寫進 `deploy/adb-notes.json`（本區）。
2. 在這一頁加一列（日期、sha 前 12、size、buildTime、工作區、說明）。
3. 要發布才跑 `publish-adb.ts`；發布後在 `deploy/adb-history.json` 由
   `make-adb-manifest.ts` 自動補機器版。
4. 工作區若日後停用，這一頁＋`deploy/adb-notes.json` 就是維護者唯一的線索。
