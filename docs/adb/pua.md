## 5. 之後怎麼處理（建議）

1. **先查書影**：每個 `<字>` 都有 `img`（如 `001a-01`，指 kanji-database 的頁面影像），
   PUA 的那個部件多半可以直接從原書認出來。
2. **查 cjkvi 的 PUA 對照**：`swjz.xml` 的 PUA 是 cjkvi 自訂的私用區，
   他們的 `swjz.xsl`／字型（SW.ttf）裡有對應表；對到的話可以直接換成 Unicode 部件。
3. **能組就組**：如果部件都在 Unicode，IDS 本身就已經是答案，只是顯示時要組字
   （例如 `⿱艹X` 的 X 換成真字後，IDS 就完整了）。
4. **換不掉的留白**：標成 `□` 並保留 `pua.tsv` 的 `suggestion` 欄，之後人工補。

可填寫的清單：`build/pua.tsv`（欄位：pua, 次數, IDS, 字頭, 字 id, img, 建議）。
