# tx.adb 與 taixu.adb 有什麼不同

`taixu.adb` 是 2006 年隨光碟流通的《太虛大師全書》資料庫；`tx.adb` 是 2026 年
在同樣的文字上重建、再加上**大正藏經文連結**的新版。兩本的正文逐字相同，差別在
資料庫檔頭、索引重建方式，以及新版多出來的 `<聯 i="taisho?…">` 跨庫錨點。
舊版已從公開資料庫下架，新讀者請用 `tx.adb`。

## 一眼看差異

| 項目 | taixu.adb（舊版，已下架） | tx.adb（2026 連結版） |
|---|---|---|
| 檔頭 `dbname` | `taixu` | `tx` |
| 資料來源 | 2006 年光碟版文字 | 同一份文字（沒有改字） |
| 行數 | 214,956 | 214,956 |
| 頁（`頁 id`） | 16,441 | 16,441（完全相同） |
| 標記種類／caches | 120／37 | 120／37（相同） |
| 大正鏈結 | 0 | **4,484 個 `<聯>`（2,450 筆引文、1,204 頁）** |
| 字級範圍 | 沒有 | **4,337 個帶 `j="起-訖"`**（其餘沿用 `q` 比對） |
| 反向連結 | 沒有 | 大正藏頁面可回連太虛 |
| 封面 | `taixu_logo.png`（259,836 B） | `tx_logo.png`（320,214 B，「2026年新版」） |
| 資源 | 678 個 | 678 個（只換 logo） |
| 檔案大小 | 20,475,406 B（19.5 MiB） | 21,685,303 B（20.7 MiB） |
| 建置日期 | 2006-01-20 | 2026-10-28 |
| 重建方式 | Delphi 版索引器 | 一支腳本（見 `taixu-links.md`） |

## 一、資料來源與做法

舊版是 2006 年用 Accelon3 的 Delphi 索引器建的，正文與目錄都在 adb 裡，沒有大正藏連結。

新版**沒有換底本**：直接把舊 `taixu.adb` 的 `source` 解成 accelon3 標記（一行一個
pcl 行），在文字上插入連結，再用 `ts/src/adbauthor.ts` 重建
`source / tokens / tags / tables / attributes / attributes.sorted / caches`，
`resources` 與 `caches` 的鍵都沿用原檔。所以：

- 把新舊文字的所有標記去掉後，**逐字相同**（214,956 行）。
- `頁 id` 16,441 筆的順序與內容完全相同。
- `caches` 37 個鍵的長度與內容完全相同（`節` 697、`項` 675、`章` 1,441…）。

## 二、新版多了什麼

- **4,484 個大正藏錨點**：`<聯 i="taisho?8p749b" q="…" j="52-60">經文…</聯>`，來自書中
  「經曰：」「經上說：」「經云：」「法華云：『」「：『」後面的引文；2,450 筆成功
  對到大正藏，分佈在 1,204 頁。`q` 帶著大正藏原文，所以能反過來在大正藏頁面上
  顯示「回連結」。
- **字級範圍 `j`**：`j="52-60"` 是目標頁「可見漢字」的起訖索引（0 起算、end 不含），
  4,337/4,484 個錨點有；點下去 accelon26 只塗那一小段（不是整頁或整欄），
  對不上 `q` 時才退回文字比對。`聯.i` 格式不變，舊 accelon3 忽略 `j`。
- **多庫反鏈**：和 `ys.adb` 一起開時，大正藏一頁的回連結會同時列出印順與太虛；
  兩庫共同引用 224 頁、54 部經（見 `shared-xref-tx-ys.md`）。
- **新封面**：`logo/tx_logo.png`（「2026年新版」），資源名 `tx_logo.png`，
  本文區空白時顯示。
- **檔名／dbname 改成 `tx`**：與 `ys.adb` 的命名一致；反連結靠檔頭 dbname 找庫，
  所以檔名、dbname、logo 資源名三者都是 `tx`。

## 三、與舊版不同的地方

- **`dbname` 由 `taixu` 改為 `tx`**：檔案叫 `tx.adb`，閱讀器才找得到來源庫；
  對外的大正連結（`taisho?…`）不受影響。
- **VA 表重算**：`tables/lines.virtual` 由新索引器重建，與舊檔最多差 52 個 VA
  （Delphi 版對少數自閉合標記的計法不同）。頁的定位一律走
  `attributes/頁.id → tags/頁`，所以頁碼不受影響。
- **標記順序**：`聯` 因為新版到處都有，在 tag 表裡的位置提前了；標記集合仍是
  120 種，`andtagid=18`（頁）與舊版相同。`平裝`／`精裝` 這種「自閉合但仍有
  close hit」的舊 docdef 寫法也照原樣重建。
- **檔案變大 1.2 MiB**：多出來的 `<聯>` 標記、`聯.i`／`聯.q`／`聯.j` 屬性與新 logo。
- **沒有改到的**：正文、頁碼、目錄層級、`u=` 屬性、圖片（678 個資源只換了 logo）。

## 四、怎麼重建

```bat
:: 1) 從舊版重建出加好連結的 tx.adb（會先寫 build/taixu-linked.txt）
bun run ts/tools/backlink.ts --src build/taixu-original.adb --reuse ^
  --dbname tx --logo logo/tx_logo.png --out build/tx.adb

:: 2) 重跑搜尋（不用 --reuse）會重新抽引文、查大正藏，約 30 秒＋打包 90 秒
bun run ts/tools/backlink.ts --src build/taixu-original.adb ^
  --dbname tx --logo logo/tx_logo.png --out build/tx.adb
```

需要 `build/taixu-original.adb`（舊版備份）與 `accelon3/taisho.adb`。
完整規則、命中率與驗收見 `taixu-links.md`。
