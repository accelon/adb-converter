# off → Accelon XML（`.off` 轉換規格）

> 2026-11-02。對象：pitaka／accelon22 的 `.off` 來源（offtext 標記），轉成 adb 的文字層
> （Accelon XML，一行一個 adb 行）。工具：`ts/tools/off2accelon.ts`。
> 這一頁是可重用的規格；每個庫的來源、參數與數字記在該庫自己的工作區。
>
> 為什麼要這一頁：`.off` 是舊工具鏈的來源格式，adb 是成品；兩者之間的**標籤對照、行／段規則、
> 註文放哪裡**每次都要重新決定一次。決定一次、寫下來，之後每一庫照做。

---

## 1. 兩邊是什麼

| | `.off`（來源） | Accelon XML（目標） |
|---|---|---|
| 單位 | 一行一個實體行（一句一行） | 一行一個 adb 行 |
| 標記 | `^tag`（offtag），無收尾標籤 | `<tag>`／`</tag>`／`<tag/>` |
| 範圍 | 由標籤自己帶（夾文／寬度），或「到下一個標籤」 | 文字流裡的**點**；範圍＝到下一個同名標籤（不保證合法 XML） |
| 標籤定義 | `0.off` 的 `^:` 宣告＋各庫的 `format/*.js` | 外部 docdef／文字裡的 `t=`／`s=`（本規格不處理，見 §7） |
| 成品 | pitaka 打包（accelon22 的 jsonp／`.ptk`） | `authorAdb()` → `.adb` |

**只轉文字，不轉格式。** 這一階段不產生 `.adb`；打包是各庫 `pack.ts` 的事。

## 2. `.off` 語法（實測，足夠處理 cs／sc／cs-mm 家族）

```text
^bk#dn1(သီလက္ခန်ပါဠိတော်)
 │  │   └ 夾文（括號內的文字；括號配對的 Unicode 相差 1，如 () （） 「」【】）
 │  └ 壓縮 id（`#` 可省略：`^n12` 等於 `^n#12`）
 └ 標籤名（ptk 只認 `[a-z_:]`；**不能有數字**）
```

- `^subhead2` → 標籤名 `subhead`＋id `2`（gen 從 `<h3>` 轉來的標題層級）。
- 標籤後的**空白不是內容**，只是分隔。
- 標籤後面沒有括號時，`^subhead ၁-နဠဝဂ်` 的「內容」是**到下一個 `^` 為止的文字**。
- `^:`（例 `^:<ptk=cs-mm zh=緬|緬譯三藏 …>`）是宣告，不是正文；轉換時略過。
- 沒有 `^^` 轉義、沒有 `^[引用]`（這兩個家族都沒有）。

### 2.1 兩種標籤

| 種類 | 行為 | 例 |
|---|---|---|
| **里程碑** | 只是一個點，後面文字是正文 | `^n7` 段號、`^pb12` 原書頁界、`^f3` 註號、`^unindent` |
| **block** | 標籤後面（到下一個標籤）的文字是它的內容 | `^centertitle`、`^subhead 標題`、`^bk#dn1(書名)` |

> 夾文是「block 的內容」。里程碑的夾文（`^unindent(ရဟန်းသည်)`）是**正文的一部分**，
> 括號要留著（ptk 的顯示也留著）。

## 3. 對照表（canonical，2026-11-02 作者定）

| off | Accelon XML | 種類 | 說明 |
|---|---|---|---|
| `^ak#dn(…)` | `<區 id="dn">(…)</區>` | block | 部／尼柯耶 |
| `^bk#dn1(…)` | `<書 id="dn1">(…)</書>` | block | 冊 |
| `^ck#d1(…)` | `<塊 id="d1">(…)</塊>` | block | **塊（chunk）**：長部／中部的一經、相應部的一相應、增支部的一集 |
| `^ckan#a1a(…)`／`^cksn#s1a(…)` | `<小塊 id="a1a">(…)</小塊>` | block | 塊再細分（SC 的巴利才有） |
| `^n7` | `<段 n="7"/>` | 里程碑 | **段號**；定位用（§6） |
| `^pb12` | `<pb n="12"/>` | 里程碑 | 原書頁界（緬甸版頁碼；**不是**定位用的頁） |
| `^f3` | `<註 n="3" pg="d1.7"/>` | 里程碑 | 文內註號；`pg` 見 §5 |
| `^fn3 注文` | `<釋 n="3" pg="d1.7">注文</釋>` | — | 註文，**另一本檔**（§5） |
| `^centertitle` | `<居中>title</居中>` | block | 緬版的小節／經末；留在原行（§4.3） |
| `^title書名` | `<題>書名</題>` | block | 書題 |
| `^chapter…` | `<章>…</章>` | block | |
| `^subhead…` | `<節>…</節>` | block | |
| `^subhead2…` | `<項>…</項>` | block | h3；與 `subsubhead` 同層 |
| `^subhead3…` | `<目>…</目>` | block | h4 |
| `^subsubhead…` | `<項>…</項>` | block | |
| `^unindent` | `<頂格/>` | 里程碑 | 「這一段不縮排」；不帶文字 |
| `^z1(經名)`／`^z2(品)`／`^z3(小節)` | `<篇>`／`<章>`／`<節>` | block | 目錄層級在 id（yh、hz） |
| `^h(小標題)` | `<小節>…</小節>` | block | 行內小標題（ccc、yh） |
| `^sz ` | `<偈/>` | 里程碑 | 偈頌行（CBETA `<l>`；yh） |
| `^m12` | `<m n="12"/>` | 里程碑 | **該譯本自己的段號**（PTS／原書），不是緬甸版的 `n` |
| `^miss` `^doubt` `^empty` | `<缺/>` `<疑/>` `<空/>` | 里程碑 | pku／yh 的標記 |
| `^p1` `^a(1)` | `<pb n="1"/>` `<錨/>` | 里程碑 | 殘留的頁／錨標記（ccc an1 各 1 個） |
| `^head` `^classe` `^trailer` `^end` `^b` `^nn` | `<首>` `<類>` `<尾>` `<終>` `<b>` `<nn>` | 混合 | cs 家族幾乎沒用到 |

- 名字原則：能沿用既有 adb 的就沿用（書／頁／章／節／註／釋）；作者定的四個結構標籤是
  **區／書／塊／段**（`ak`／`bk`／`ck`／`n`）。
- **不輸出 `<頁>`**（作者 2026-11-02）：定位字串就是 `塊.段`，閱讀器 `anchorVa()` 找不到
  `頁.id` 時會退回查 `attributes/塊.id` ＋ `attributes/段.n`，所以跨庫 `<聯 i="yh?a6.7">`
  不需要頁標籤。`--pageid "{ck}.{n}"` 只是保留給真的要頁標籤的場合。

## 4. 行與版面規則

### 4.1 一行對一行（作者 2026-11-02）

- **來源幾行，輸出就幾行**：不併行、不刪空行，標籤（`<居中>`、`<段>`…）可以和文字接在
  同一行。行數一致，使用者捲動時就能直接比對不同譯本。
- 平行文本靠行號對齊；`段` 是靠語意的錨（§6）。
- **唯一例外**：超過 **4,096 字**的行要切開（accelon3 的 `lines.physical` 上限 8,192 bytes，
  見 `adb-knowhow.md` §3）→ 會多出行，且切點之後的行號會平移；報告的「切行」欄會列出來。
  切點優先 `။`／`၊`／空白，不切進標籤、不切開代理對，可以的話也不切在標籤內容中間。
- 想讓 `<居中>` 自成一行（會多出行）可以加 `--centers alone`，但**預設不做**：行數一致
  比較重要。

### 4.2 空行
原書空行照留（`lines.physical` 仍是行的單位）；它們沒有語意，只是保留行號對應。
要壓掉可以加 `--blank 0`（本規格不建議，會破壞行號對應）。

### 4.3 `<居中>` 的位置

`^center` 是**緬版的小節**，其他譯本可能沒有（作者 2026-11-02）。它照樣留在原來那一行：

- 行尾的 `^center`（文字在下一行）：標籤搬到下一行，包住那一行開頭的文字（§4.4）；行數不變。
- 和正文同一行的 `^center`：就留在那一行，`<居中>…</居中>` 與前後文共用一行。

> 這一條 2026-11-02 改過一次：先做成「`<居中>` 自成一行」，後來作者指示以行數一致為準，
> 所以改回「留在原行」。`--centers alone` 保留給需要時使用。

### 4.4 標籤在行尾、文字在下一行

`.off` 有 1,790 處把標籤寫在行尾、文字寫在下一行（例 `…။^center` 換行 `ပဌမသုတ်။`）。
轉換時把標籤**搬到下一行**、包住那一行開頭的文字：行數不變，標籤也對到真正的文字。
搬不成的（下一行沒有可包的文字）就留在原行尾變成空標籤。

### 4.4 文字正規化（只有這些）

| 動作 | 原因 |
|---|---|
| `&nbsp;` → 空白、Tab → 空白 | HTML 殘留；別讓 `&` 進 adb |
| 行尾空白刪掉 | |
| 夾文括號**保留**（`(書名)`） | ptk 的顯示也含括號；不保留就等於改字 |
| block 內容頭尾 trim | `^subhead 標題` 的那個空白是分隔，不是內容 |

> `^subhead (၆) ^f1 -အဝိဇ္ဇာဝဂ်` 這種「標題裡夾註號」的寫法，標題會在註號處斷開，
> 註號後的文字仍是正文（**不丟字**）。這是刻意選的：反過來（讓里程碑不中斷標題）會把
> `^subsubhead 經名^f10正文…` 的整段正文吸進標題。

## 5. 正文與註文分檔（作者 2026-11-02）

- 正文：`<書>.xml`；註文：`<書>-fn.xml`（**一條 `<釋>` 一行**）。
- `^fN` → `<註 n="N" pg="塊.段"/>`；`^fnN 注文` → `<釋 n="N" pg="塊.段">注文</釋>`。
- `pg` 取「它所在段落的頁 id」＝`塊.段`（和之後補的 `<頁 id>` 同一個字串），
  閱讀器 `notes.ts` 先比 `pg`、再比頁、再比距離；編號不重編（保留原書的每頁重編）。
- 找不到段落（來源的 `^n` 在正文裡不存在）的註群組：`pg` 留空，報告列「無pg」。

## 6. 定位：`塊.段`（ck.n）

- 跨語言穩定的錨是 **`ck`（塊）與 `n`（段）**：`a6.7` ＝ 增支部第六集第 7 段。
- 小標題（`center`／`subhead`／`subhead2`…）**可能有出入**：譯本可能沒有、可能多、可能是
  譯者加的。所以對齊**不要用小標題**。
- 有些版本有漏譯、或把譯者注混進正文；絕大部份時候文句仍逐行對應（作者 2026-11-02）。
- **不用 `<頁>` 標籤**：`塊.段` 直接由 `attributes/塊.id` ＋ `attributes/段.n` 解析
  （閱讀器 `page-text.ts` 的 `anchorVa()` 在沒有 `頁.id` 時退回這條路）。
  跨庫寫 `<聯 i="yh?a6.7">` 就能跳；同一塊裡的段號重複（xsq 每經重編）也不會跳錯塊。
- **句層級**（2026-11-02）：`塊.段:句`（`d1.7:3`，1 起算）。解析時用 `lines.virtual`
  （每一行最後一個 token 的 VA）找段標記所在行、往後推 `j-1` 行，並夾在下一段之前；
  不需要在正文加 `<句>` 標籤。注意 **VA 是 token 計數、不是字元位移**
  （`index-builder` 的 `addtoken`；`fullTextIndex:false` 時仍照 token 前進）。
- **目錄樹**（作者 2026-11-02）：`00.xml` 第二行是
  `<隱><樹 s="*" t="區,書,塊.">目錄</樹></隱>`；`區` 帶 `t="書."`、`書` 帶 `t="塊."`。
  三層：部（區，4 個）→ 冊（書，22）→ 塊（252–1,259）。`s="*"` 讓輸入區出現
  （沒有 tokens 時搜尋為空，但輸入框在）。沒有 `區` 的庫（xsq 現在也補了）自動退成兩層。
- **缺的 `區` 要補**：來源只在每個部類的第一冊寫 `^ak`（dn1／mn1／sn1／an1 等）；其餘各冊
  靠「文件順序中最近的前一個上層」歸部。若連第一冊都沒有（cs-mm 的 an1、xsq 全部），
  轉換時在該冊 `書` 前面補一個 `<區 id="an" t="書." n="an"/>`（不加文字、行數不變）。
- **區／書 的順序要正**：少數來源把 `^ck`／`^bk` 寫在 `^ak` 前面（sc 的 `mn1`、ccc 的 `an1`），
  轉換時把區與書搬到第一個塊之前（只搬標籤與它的文字，不增刪；驗收會列「文字順序調整」）。
- **塊的目錄名**：`塊` 有夾文就用夾文；沒有就用同一行前面最近的標題（`節`／`項`／`小節`…）
  寫進 `n=`；再沒有就用 `id`。這只影響目錄顯示，不動 `id=`、不動正文。
  （yh／ccc 的塊多半沒有夾文，沒有這個補救目錄會一片空白。）

**實測（2026-11-02）**：`sc`／`yh`／`ccc`／`pku`／`hz` 22 本書的 `段` 序列與 `cs-mm`
**完全相同**（共 6,554 段），可以直接用 `塊.段` 對照。

## 8. 指令

```powershell
# 通用（母工作區）
cd D:\2026\adb-converter
bun run ts/tools/off2accelon.ts --src <off 目錄> --out <輸出目錄> `
  --glob "*.mm.off" --strip ".mm.off" --notes "-fn.off" --notesout "-fn" `
  --dbname cs-mm --dbcname 緬譯巴利藏 --enname "Tipitaka Myanmar" `
  --report <報告檔>

# sz 工作區（來源清單固定，從零重跑用這個）
cd D:\2026\sz
bun run src/off2accelon.ts          # cs-mm + sc
bun run src/off2accelon.ts cs-mm    # 只轉緬譯
```

主要選項：`--pageid`（頁 id 模板，預設不輸出 `<頁>`）、`--pg`（註文 pg，預設 `{ck}.{n}`）、
`--blank`（空行，預設保留）、`--centers alone`（`<居中>` 自成一行，預設留原行）、
`--maxlen`（預設 4096）、`--limit`／`--dry`（除錯）、`--check`（驗收，見 §9）。

## 9. 驗收清單（每次轉換都要跑）

**一行指令**（母區工具內建，會回傳 exit code）：

```powershell
bun run ts/tools/off2accelon.ts --src <off 目錄> --out <輸出目錄> `
  --glob "*.mm.off" --strip ".mm.off" --check
```

它會比對：

1. **正文沒掉字**：來源去掉 offtag（夾文留括號）後的字串，要等於輸出去掉 `<…>` 後的字串
   （忽略空白）。這一項抓過 `^unindent(…)` 夾文被吃掉、`&nbsp;` 沒清兩個 bug。
2. **`<段>` 序列**：數量與順序要和來源 `^n` 一致（`^n` 可以是範圍，如 `553-586`）。
3. **結構**：沒有殘留 `^`、沒有裸 `&`、正文裡沒有 `<`／`>`、標籤語法正確、行長 ≤ 4,096。

另外人工看兩項：

4. **行數**：除切長行的書以外，輸出＝來源（報告的 1:1 欄）。
5. **註**：`<註>`／`<釋>` 數量和來源 `^f`／`^fn` 一致；報告的「無pg」比例合理。

### 9.1 轉換時做的文字正規化（只有這些）

| 動作 | 原因 |
|---|---|
| `&nbsp;` → 空白、Tab → 空白 | HTML 殘留 |
| 掉 `</?[a-zA-Z]…>` | **offtext 不該有 HTML**（作者 2026-11-02）：ccc 有 `<br>`、`<a …>`、`</a>`、`</span>`；標籤丟、文字留 |
| 正文裡孤立的 `<`／`>` → `＜`／`＞` | ccc an7:439 的錯字；留著會被當成標籤 |
| 孤立的 `^`（`^n3^` 的續行記號）丟掉 | ptk 也丟 |
| `^n553-586undefined` → `553-586` | 來源樣板漏字（`undefined`），否則 id 會變垃圾 |
| `^n1.` → id `1` | xsq 的 PTS 段號後面帶句點 |

**每一處清除都留紀錄**：`--cleanup <檔>`（sz 的預設是 `out/<db>-cleanup.tsv`），
欄位是「書／行／種類／片段」，例如：

```text
書	行	種類	片段
sn2	5927	html	<a href="../Ud/Ud65.htm" target="xxx">
sn2	5927	html	</a>
an7	439	angle	（孤立）<
```

**來源檔不動**（`D:\2023\...` 是唯讀的產生器產物）；要根治請改該庫的 `gen.js`／`cleanhtml.js`。
報告（`out/<db>-report.txt`）也會列「清除紀錄」一節與逐書統計。

### 9.2 夾文（括號）

- 括號**要配對**：`^h((1)有偈篇)` 的內容是 `(1)有偈篇`，不是 `(1`。
- 夾文**裡面可能還有 offtag**（yh 的 `『…^f2…』`）：要遞迴轉，不能原樣貼上。
- 夾文的外圍括號**保留在正文**（ptk 的顯示也是這樣）；要乾淨的目錄名，在 adb 階段去括號。
- 夾文後面緊接的文字：只有**書／塊／區**這類 id 標籤才算標題的另一半（SC 的
  `^ck#d1(Brahmajāla )1. Talk…`）；標題標籤（`^h(小標)正文…`）後面的文字是正文。

### 11.1 巴利底本 `cs`：儉約巴利＋詞譜（2026-11-02）

來源不是普通 offtext，而是作者自研的 **provident-pali**（儉約巴利）＋**詞譜**：
一個詞可以寫成 `pd3Upm`（pada ＋ 連音 3 ＋ upama）。轉換時多了三件事：

| 事 | 做法 |
|---|---|
| 正文字母 | 用 provident-pali 的 `orthOf()` 還原連音、`toIAST()` 轉 IAST（只在**轉檔時**用，adb 不引用這個套件） |
| 保留拆詞 | 每個詞譜詞輸出 `<詞 b="pd\|upm" j="3">padopama</詞>`：`b` 是詞譜原文分段、`j` 是連音編號，join 起來就是原詞譜（一字不差） |
| 塊 id 唯一 | 義注加 `a`、複注加 `t`、再複注加 `x`（例 `dn1a` 的塊 `d1a`） |

為此共用工具加了四個選用參數（不影響原有資料集）：

```ts
convertOffDir({
  books: [...]            , // 只轉這幾本（依序）
  text: (s, plain) => ...  , // 正文轉寫器；plain＝正在渲染節點名字（不要插行內標籤）
  ckTransform: (id, bk) => id + layerOf(bk), // 塊 id 正規化
  areaOf: (bk) => 'abh'    , // 沒有 ^ak 的書要用哪個部類
})
```

另外兩處順手的修正：`^t@ds.251g3aAdyO` 只把「書.頁[g偈]」當連結目標
（後面緊貼的詞還給正文，`<聯 j="ds.251g3"/>`）；`^n `（空段號）不產生 `<段>`。

實測 24 冊：133,920 行、8,017 段、650 塊、1,078,357 詞、168,354 個 `<詞>`，
逐冊「行數／段／塊／字母數／詞譜數」全部相符（`D:\2026\sz\src\cs2accelon.ts --check`）。
