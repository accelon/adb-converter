accelon26 分區示意圖

所有分區的名稱一律以 DOM id 為準（紅字）；分頁面板另外標 [data-tab=…]。 這份檔案由 ts/tools/gen-map.ts 從 ts/src/accelon26/accelon26.template.html 掃出來， bun run tools/check-map-ids.ts 會雙向比對它和 build/accelon26.html。

對應產物：build/accelon26.html（file:// 版）與 wails/assets/index.html（桌面版，同一份）。
