# jingqun — 大正藏「經／論／律 → 注 → 疏」繼承表

把 `taisho.adb` 的 3,000 部書，按「所釋的本經／本論」串成繼承樹：

```
經／論／律（root） → 注（直接釋經、釋論或釋律） → 疏（釋注，可再往下）
```

第三版覆蓋 **釋經論部、經疏部、續經疏部、論疏部、續論疏部、律疏部、續律疏部**，以及
**諸宗部／古逸部**中可判定的註疏，共 **379 部註疏**、**479 個節點**、**81 個群（含論群、律群）**。

## 文內嵌入 `<嵌>`

在經文段落前插：

```text
<嵌 q="如是我聞：一時，佛在舍衛國…" t="jingang?33p228b@318-360@註解|jingang?25p781b@97-127@天親論|jingang?33p155c@271-300@纂要" n="3 家注疏"/>
```

點「▸ 3 家注疏」→ 在該段下方列出三家對同一段經文的解釋；再點或按「收合」移除。
金剛經 pilot：7 部書、92 群、成品 `build/jingang-group.adb`。
完整流程與限制見 [`docs/adb/jingqun-embed-skill.md`](../docs/adb/jingqun-embed-skill.md)。

## 資料模型

`jingqun.tsv` 的欄位：

| 欄 | 說明 |
|---|---|
| `family` | 經群代號（同一部經／論的不同譯本歸一族） |
| `class` | **經**／**論**（root）／**注**（直接釋經或釋論）／**疏**（釋注，depth ≥ 2） |
| `depth` | 0 = 經／論，1 = 注，2 = 疏，3 = 疏之疏 |
| `idx` | adb 的書序；對應 `<書 id="n{idx}">` |
| `no` | 大正經號（`1510a` 這種後綴照原樣） |
| `title` / `author` | 題名／譯者·作者 |
| `genre` | 題名上的體裁：論、疏、記、鈔、玄義、大意… |
| `parent_no` | 直接所釋的那一部（root 或另一部注疏） |
| `root_no` | 本群的根本經（或根本論） |
| `conf` | high／medium／low |
| `evidence` | `cf:No.N`（CBETA 交叉引用）、`manual`（人工種子）、`root` |
| `note` | 版本、別譯、闕經等說明 |

**class 是「輩分」，不是「體裁」**：直接釋經的《金剛般若經疏》是「注」，
釋《金剛般若經疏論纂要》的《金剛經纂要刊定記》才是「疏」。實際體裁看 `genre`。

## 證據從哪來

1. **CBETA 的 `[cf. No. N]`（最強）**：TEI 正文第一行常是
   `No. 1698 [cf. No. 235]`，表示本部註疏所釋的是 T235《金剛般若波羅蜜經》。
   這行也原樣保存在 `taisho.adb` 內文，所以關係不是猜的。379 部中有 179 部自帶 cf。
2. **人工種子**：續經疏部、續論疏部幾乎沒有 cf；論疏部也有幾部沒有。
   依題名、部類次序、以及「疏的疏」再分層指定（其餘 200 部）。
3. **cf 指到另一部註疏時**：它是 parent，不是 root。例如
   `T1833 演祕 [cf. No. 1830]` → parent T1830 述記、root T1585 成唯識論。
   build.ts 用 `CF_PARENT` 表處理。

### 幾個 cf 修正了常識的地方

- T1704《金剛般若波羅蜜經略疏》cf 指 **T236**（菩提流支譯），不是通行的 T235。
- T1705–1708 仁王經疏 cf 指 **T245**（舊譯），T1709 才指 T246（不空新譯）。
- T1763《大般涅槃經集解》cf 指 **T375**（南本），T1764《義記》才指 T374（北本）。
- T1798《金剛頂經大瑜伽祕密心地法門義訣》cf 指 **T867 瑜祇經**，不是金剛頂經。
- T1517/T1518 互指（cf 指向對方），不是根；兩部都釋 T257 聖佛母般若。
- T1521《十住毘婆沙論》釋 **T286 十住經**（十地品舊譯），不是 T287 十地經。
- T1526《寶髻經四法憂波提舍》釋 **T397 大集經**寶髻品，不是大寶積經。
- T2800《廣百論疏》cf 指 **T1571 大乘廣百論釋論**，不是 T1570 廣百論本。

## 重跑

```powershell
# 來源預設 D:\2023\sat2018\T 與 D:\2023\sat2018\taisho.tsv
bun run jingqun/catalog.ts   # 3,000 筆書目（讀 3,000 個 TEI 檔頭）
bun run jingqun/cf.ts        # 3,000 個檔的 cf 掃描
bun run jingqun/build.ts     # 繼承表 + JSON
bun run jingqun/render.ts    # HTML
bun run jingqun/check.ts     # 驗證
```

可用環境變數換來源：`TAISHO_TEI`、`TAISHO_CATALOG`。
